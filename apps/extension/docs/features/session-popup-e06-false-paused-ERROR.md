## 오류 제목

- 사이트 접근 꺼짐(E06) 화면이 세션 상태와 상관없이 "세션이 자동으로 멈췄어요"라고 함

## 실행 환경

- macOS 버전: 26.6.1 (Darwin 25.6.0)
- Chrome 버전: Chrome for Testing 153.0.8010.12 (Playwright Chromium, `--load-extension`)
- Extension 버전: 0.1.0 (빌드 결과물 `out/`)
- Desktop 연결 상태: 실제 로컬 서버(dev 최신)로 연결
- 권한 상태: 사이트 접근 꺼짐, 서버 주소 host 권한 있음

## 재현 방법

1. 사이트 접근을 허용하지 않은 채 연결한다.
2. Desktop에서 집중을 시작하고 팝업을 연다.

## 기대 결과

- 집중이 계속되는 중이면 탭을 확인하지 못한다고만 안내한다. 실제로 멈췄을 때만 멈췄다고 한다.

## 실제 결과

- Desktop은 `RUNNING`인데 팝업은 "그래서 세션이 자동으로 멈췄어요"와 `마지막 확정 남은 시간`을 보여 줌.

## 원인 및 해결

- 추정 원인: 권한 해제 알림(`local-events`) 뒤 서버가 세션을 멈추지 않았다.
- 실제 원인: 추정과 달랐다(이 경우는 권한을 처음부터 허용하지 않아 알림이 나간 적이 없음). 화면이 세션이 끝나지 않았기만 하면 서버가 이미 멈췄다고 가정하고 문구를 고정해 두었다. 알림이 서버에 닿지 못한 경우(CORS, `extension-host-permission-cors-ERROR.md`)에도 같은 거짓 안내가 나온다.
- 해결 방법: 서버 상태가 `PAUSED`·`AUTO_PAUSED`일 때만 "세션은 멈춰 있어요 · 다시 허용한 뒤 직접 재개해 주세요"와 `멈춘 시점 남은 시간`을 보여 주고, `RUNNING`이면 "지금은 Chrome 탭을 확인하지 못해요. 다시 허용해 주세요"로 안내한다. 사용자가 직접 멈춘 경우도 있어 "그래서"를 뺐다.
- 변경 파일: `features/session/SiteAccessStep.tsx`

## 확인 결과

- [x] 같은 방법으로 재현되지 않는다. (RUNNING → 탭 확인 불가 안내, PAUSED → 멈춤 안내 + 24:55로 Desktop과 일치)
- [x] 관련 기능의 회귀가 없다. (`pnpm test`)

## 재발 방지 및 남은 작업

- 서버 상태를 추정해 문구를 정하지 않고, 받은 상태로 나눈다.
