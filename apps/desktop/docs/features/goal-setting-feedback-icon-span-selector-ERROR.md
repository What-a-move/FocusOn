## 원인 및 해결

- 추정 원인: 아이콘 크기 값이 다른 규칙에 덮였다.
- 실제 원인: 본문 줄바꿈용 `.feedback span { display: block; }`이 아이콘 안의 `span`에도 걸렸다. 시안 HTML 규칙을 그대로 옮기면서 선택자 범위가 넓었다.
- 해결 방법: 본문 쪽만 가리키도록 `.goal-window .feedback div span`으로 좁혔다.
- 변경 파일: `features/goal/goal.css`
