# 할 일 적기 - AI 질문 시간 초과 오류

## 증상
할 일을 적고 저장하면 AI 질문 대신 「할 일을 살펴보지 못했어요. 인터넷 연결을 확인해 주세요.」가 떴다. 서버와 AI는 정상이었다.

## 실제 원인 (측정함)
- 서버 로그: `/api/v1/goals/clarify`가 12.4초·11.5초 걸려 200으로 끝났다.
- Desktop은 모든 요청을 `AbortSignal.timeout(10_000)`으로 10초에 끊는다. 응답이 오기 전에 끊겨 `LOCAL_NETWORK_UNAVAILABLE`(timeout)이 됐고, 화면은 인터넷 오류 문구를 보였다.
- AI 서버 안에서 잰 시간: Claude를 차례로 2~3번 부르고(생성 → 검증 → 다시 만들기) 한 번에 2~4초씩 걸려 약 10초가 나왔다.
- 서버는 AI 호출 한 번에 60초까지 기다리고 실패하면 최대 2번 다시 부른다.

## 고친 방법
- `AuthorizedRequest`에 `timeoutMs`를 두고 기본은 10초로 유지했다.
- AI를 부르는 요청(`/goals/clarify`, `POST /goals`)만 70초까지 기다린다(`AI_TIMEOUT_MS`).

## 확인
QA 앱 `FocusOn-QA-357-c03d347`에서 「ds 힙 정리하기」를 적고 10초 뒤 질문 화면(질문 1 / 2)이 떴다.

## 따로 남은 것 (AI 쪽)
「자료구조 공부하기」는 AI가 같은 제목의 후보를 만들어 다시 만들기 단계에서 500으로 끝난다. Desktop은 「입력한 그대로 저장」으로 넘어간다.
