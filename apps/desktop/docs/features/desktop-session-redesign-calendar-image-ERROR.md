# 하루 목표 달성일 포키 이미지가 사각으로 잘리는 문제

## 재현

하루 목표를 달성한 날짜를 집중 달력에서 보면 배지 옆 포키 이미지 가장자리가 원형 테두리 밖으로 보인다.

## 원인과 수정

달성 체크 배지는 날짜 칸보다 밖에 위치한다. 이를 표시하기 위해 부모의 overflow를 풀었을 때 이미지도 함께 마스크 밖으로 보였다. 부모는 배지 공간을 계속 열어 두고 포키 이미지만 부모의 원형 모서리를 상속하도록 했다.

## 검증

합성 달력 응답으로 달성일을 열어 이미지의 원형 모서리, 날짜 칸의 overflow 상태, 배지 표시를 확인했다.
