# 보통 알림 단계가 시간 경과 뒤에도 누적됨

- 기능 F04, Desktop, 2026-11-19, #282
- 상태 해결. 수정 전 회귀 테스트에서 재현했다.

## 재현과 기대 결과

가짜 시계로 같은 세션의 보통 팝업을 0분, 9분, 19분, 29분 1ms에 표시한다. 기대 단계는 1차 → 2차 → 1차 → 1차였다. 수정 전에는 1차 → 2차 → 적극 → 적극이었다.

## 원인 및 해결

- 추정 원인 — 이전 전경에서 생긴 알림이 늦게 표시되거나 횟수 초기화 조건이 빠졌다고 봤다.
- 실제 원인 — `InterventionWatcher`가 횟수만 보관해서 마지막 보통 팝업 표시 시각과의 간격을 판단할 수 없었다.
- 해결 — 기존 `Deps.now`를 사용해 성공한 보통 팝업 표시로부터 10분을 재고, 만료 경계부터 다음 보통을 1차로 시작한다. 약하게·적극 표시와 세션 초기화에서 기존 초기화 동작을 유지한다.

## 확인 결과

추가 테스트 3개로 10분 안의 연속 표시, 만료 경계와 초과, 약하게·적극 사이에서의 초기화를 확인했다.
