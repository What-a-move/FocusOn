## 기능 목적

- 사용자의 문제: 지난 집중 기록을 날짜별로 다시 볼 곳이 없다. 사이드바 `집중 기록`은 비어 있고, 홈 달력 날짜를 눌러도 아무 일이 없다.
- Desktop에서 제공할 가치: 한 주의 집중 시간을 막대로 비교하고, 고른 날의 회차를 시간순으로 보며 회차 리포트로 들어간다.

## 사용자 흐름

1. 사이드바 `집중 기록` 또는 홈 달력의 날짜를 누른다(`/records/?date=YYYY-MM-DD`, 없으면 오늘).
2. 위쪽에 고른 날이 속한 주(월~일)의 하루별 집중 시간 막대와 주간 합계가 보인다.
3. 아래쪽에 고른 날의 총 집중 시간·회차 수와 회차 목록(시작 시각·목표·끝난 시각·집중 분)이 보인다.
4. 막대·이전/다음 주·날짜 선택·`오늘`로 날짜를 바꾼다. 미래 날짜는 고를 수 없다.
5. 회차를 누르면 세션 결과 화면(`/session-result/?session=ID`)으로 간다. 기록이 없는 날은 `집중 시작하기`로 목표 설정에 간다.

## Desktop 상세 동작

- 진입 조건: 로그인 상태. 로그아웃·만료면 설정 화면처럼 첫 화면으로 보낸다.
- 정상 동작:
  - 주간 막대: 그 주가 걸친 달(1~2개)의 `report:calendar:get`을 불러 `totalActiveMs`를 분으로 내림해 쓴다. `hasStudyActivity`가 true인 날만 기록 있음으로 표시한다(서버 기준 1분 이상).
  - 하루 기록: `report:daily:get`으로 고른 날의 세션을 받아 시작 시각순으로 보여 준다. `endedAt`이 null이면 `진행 중`으로 표시한다.
  - 같은 주 안에서 날짜만 바꾸면 주간 막대는 다시 부르지 않는다.
  - 주소의 `date`를 바꿔(replace) 새로고침해도 같은 날이 보인다.
- 종료 조건: 다른 메뉴로 이동.
- 상태 변화: 없음(조회 화면).

## 화면 및 사용자 경험

- 화면 위치: `app/records/page.tsx`, `features/records/*`. 설정 화면과 같은 사이드바 틀을 쓴다.
- 주요 컴포넌트: 머리줄(제목·이전/다음 주·날짜 선택·오늘), 주간 막대, 하루 요약, 회차 목록, 빈 날.
- 시안에서 빼는 것:
  - `기록 시안 보기`·`예시` 태그(제품에 미리보기 요소를 넣지 않는다).
  - 하루 흐름 막대(목표 활동·다른 활동…): 일간 리포트 응답에 비율 필드가 없다. 서버가 주면 그때 넣는다.
  - 회차의 `n회 연장`: 일간 세션 항목에 연장 횟수가 없다.
- 로딩·빈 상태·오류 상태:
  - 로딩: 회차 자리 skeleton 3줄.
  - 빈 날: 졸린 포키 + `이날은 기록이 없어요` + `집중 시작하기`.
  - 오류: 실제 오류이므로 빨간 안내. 제목 `기록을 불러오지 못했어요.`, 본문 `errorText`, `다시 시도`(결정 031·032).
- 홈 연결: 홈 달력 날짜(오늘까지)를 누르면 그날 기록으로, 지난 목표를 누르면 그 회차 결과로 간다. 사이드바 `집중 기록` href를 채운다.

## 데이터 및 IPC/API

- Renderer 입력: 날짜 문자열(YYYY-MM-DD), 달(YYYY-MM)
- Main 또는 Preload 전달값: 기존 `window.focusOn.reports.getCalendar`·`getDaily` (새 Channel 없음)
- Server·AI 요청 여부: `GET /api/v1/reports/calendar?month=`, `GET /api/v1/reports/daily?date=` (서버 미구현, 지금은 `404 NOT_FOUND` → 오류 안내)
- 저장 데이터: 없음
- 분석 제외 대상: 해당 없음
