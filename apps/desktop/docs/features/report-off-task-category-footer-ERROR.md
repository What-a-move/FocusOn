# 집중 리포트 홈 버튼이 화면 아래로 밀리는 문제

- 관련 [Desktop #387](https://github.com/What-a-move/FocusOn/issues/387) · [PR #388](https://github.com/What-a-move/FocusOn/pull/388)
- 발생일: 2026-11-28

## 재현 및 원인

집중 기록에서 결과를 열면 창이 낮거나 본문이 길 때 `홈으로` 버튼이 첫 화면에서 보이지 않았다. 버튼이 본문과 같은 스크롤 컨테이너의 마지막에 있어 콘텐츠 길이만큼 아래로 밀렸다.

## 해결 및 검증

공용 하단 버튼 영역을 본문 스크롤의 바깥에 배치했다. 버튼 영역이 별도 공간을 차지하므로 마지막 본문 항목도 스크롤해 읽을 수 있다. 집중 기록에서 리포트를 열고 800×600 화면의 첫 화면·중간·끝과 홈 이동을 검증했다.

## 같은 회차의 분류 기록 확인

- 로컬 QA 30회차(11월 28일 22:06 종료). 영상 관측 1건은 `UNRELATED / VIDEO`. 후속 탭과 본문 분석은 AI 응답과 서버 저장 모두 `UNCERTAIN / AMBIGUOUS_CONTEXT`였다.
- 후속 본문 분석 traceId `624edd26-4ed4-4818-b764-82639c93b2f5`, `fb8bf09b-a175-4b3a-82a8-07d17d189e59`. 서버 `ai.call.ok → store.write.ok → http.out 200`을 확인했다.
- 집계는 분류된 딴짓 1건을 사용해 영상 100%로 표시한다. 리포트에 판단 보류 제외 기준을 안내한다. 본문 판정의 정확도는 AI 쪽에서 확인할 항목이다.
