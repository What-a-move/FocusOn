## 재현 방법

1. 노치 있는 MacBook 내장 화면에서 Chrome·메모 등을 전체 화면으로 바꾼다.
2. 포키 알림을 띄운다(데모 모드 ⌘⇧D).

## 기대 결과

- 전체 화면이면 Dock이 숨겨지므로 포키가 화면 바닥에 붙는다.

## 실제 결과

- 전체 화면인데도 포키가 Dock 높이(63px)만큼 떠 있었다.

## 오류 메시지

```text
(없음) 전체 화면 창 크기 1512×949, 화면 크기 1512×982 → "화면 크기와 같다" 비교 실패
```

## 원인 및 해결

- 추정 원인: 전체 화면이면 맨 앞 창 크기가 화면 크기와 같을 것이다.
- 실제 원인: 노치 있는 화면에서 전체 화면 앱은 노치 줄(맨 위 33pt)을 비워 두고 그 아래만 쓴다. 그래서 창이 1512×949로 화면(1512×982)보다 작아 "창 = 화면" 비교가 늘 거짓이었다. 실제 창 좌표(`CGWindowListCopyWindowInfo`의 `kCGWindowBounds`)를 찍어 확인했다.
- 해결 방법:
  - Swift 도우미 `frontmost` 응답에 `fullScreen`을 더했다. 판단 기준은 "창 너비가 화면 너비와 같고, 창 아래 끝이 화면 맨 아래에 닿는다"이다. 위쪽(노치 여부)은 보지 않는다. 최대화한 일반 창은 아래 끝이 Dock 위에서 멈추므로 구분된다.
  - CG 창 좌표(주 화면 왼쪽 위가 0)와 AppKit 화면 좌표(왼쪽 아래가 0)를 맞춰 비교한다.
  - 포키가 떠 있는 동안 0.25초마다 다시 확인하고, 도우미 응답이 없으면(시간 초과 등) 기존 판단을 유지한다(PR #227, 응답 없음을 "전체 화면 아님"으로 보면 포키가 튀어 오름).
- 변경 파일: `native/observer/main.swift`, `electron/main/screen-observer.cts`, `electron/main/index.cts`, `tests/electron/screen-observer.test.cjs`
