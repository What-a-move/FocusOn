# Desktop 집중 재설계 API 연결

- 관련 이슈: [#391](https://github.com/What-a-move/FocusOn/issues/391)
- 담당: Frontend · Desktop
- 우선순위: MVP 기본
- 선행 API: #346 · #375 · #376 · #358 · #386
- 화면 기준: FocusOn-design의 session.html, settings.html, main.html, records.html, session-report.html, onboarding.html.

## 구현 순서

1. 진행 중 세션의 할 일 추가 창에서 3개가 찬 경우 교체할 위치를 골라 저장한다. 추가·버전 충돌 동작을 유지한다.
2. 설정에서 하루·주간 목표를 저장하고, 홈에 진행률·현재 연속 달성 일수·최장 기록을, 집중 달력에 서버가 확정한 하루 목표 달성을 표시한다. 주간 목표를 해제할 수 있다.
3. 종료 후 회고가 켜져 있으면 평가와 선택 사유·메모를 저장하고 다음 화면으로 간다. 건너뛰기와 저장 실패 재시도를 제공한다. 개인정보 안내에 사용 목적을 반영한다.
4. 분석 설정과 신규 온보딩의 분석 제외 단계에서 학습용 메신저를 선택하고 저장한다. 선택을 건너뛸 수 있고, 저장 실패 시 같은 단계에서 다시 시도한다. 완료 요약에는 저장된 선택 수를 보여 준다. 메신저 처리 기준을 화면 분석 동의 상세에 추가한다.

## 검증

- 서버 변경 없이 기존 세션·설정·리포트 IPC의 인가 경계를 사용한다.
- 교체 요청 검증, 이전 설정 응답 호환, 주간 목표 해제, 회고 입력 검증, 메신저 저장을 테스트한다.
