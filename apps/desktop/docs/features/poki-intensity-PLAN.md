## 사용자 흐름

1. 약하게는 좌우 아래 구석에서 무작위로 팻말을 띄운다. 4초 동안 보이고, 포인터가 올라가 있으면 벗어난 뒤 1.5초를 기다린다. 클릭하면 바로 내려간다.
2. 같은 세션에서 연속으로 받은 보통 딴짓 알림의 첫 번째는 좌우 구석에 포키와 팻말을 띄우고 클릭을 기다린다. 두 번째는 세로 최대 50%인 포키와 연한 전체 화면 흐림을 띄운다.
3. 세 번째 이후와 적극은 세로 최대 70%인 포키와 진한 흐림을 쓴다. 팻말은 직전 적극 알림과 다른 문구를 선택하고, 올라온 뒤 5초 동안 클릭을 잠근다.
4. 보통 2차와 적극은 포키·팻말을 눌러 돌아가거나 `이것도 공부야`로 공부로 표시하고 토스트를 본다.

## Desktop 구현과 데이터

- 주 모니터에만 띄운다. 구석 알림은 Dock 위치를 따라가고, 화면 전체를 덮는 알림은 Electron 투명 창과 macOS vibrancy를 쓴다. 이 창이 전체 화면 Space에 뜨는지 단독 시험한다.
- 단계는 Desktop에서 관리한다. 이미 표시한 개입을 중복 계산하지 않고 마지막 보통 팝업 표시로부터 10분이 지나면 다음 보통은 1차부터 시작한다. 약하게·적극 팝업 표시와 세션 종료·변경도 횟수를 초기화한다.
- 기존 확인 기록 API의 `ACKNOWLEDGED`와 `DISMISSED`로 처리한다. 공부 표시는 해당 개입의 해제 기록으로 보낸다.
- 흐림은 운영체제가 합성한다. 구현에서 화면 원본을 수집하거나 저장하지 않는다.
