# 제한된 실행 환경에서 Desktop 테스트가 실패함

- 기능: 강도별 포키 딴짓 알림
- 관련 이슈: [#282](https://github.com/What-a-move/FocusOn/issues/282)
- 발생 일시: 2026-11-19
- 환경: macOS 26.6.1, Node.js 24.14.1
- 상태: 해결

## 재현과 실제 결과

제한된 실행 환경에서 `pnpm test:electron`을 실행했다. Swift 빌드는 기본 컴파일 캐시 디렉터리에 쓸 수 없었다. 캐시를 옮긴 뒤 기존 Google OAuth의 로컬 리스너 테스트가 실패했다.

## 원인 및 해결

- 추정 원인: 첫 실행에서는 Swift 표준 라이브러리 문제로, 두 번째 실행에서는 OAuth 테스트 자체의 문제로 보였다.
- 실제 원인: 첫 실패는 기본 캐시 경로 쓰기 제한이었다. 두 번째 실패는 로컬 루프백 서버를 열 수 없는 실행 제한으로 재현됐다.
- 해결: 쓰기 가능한 임시 경로에 모듈 캐시를 지정하고 로컬 리스너를 열 수 있는 실행으로 동일한 테스트를 돌렸다. 기존 테스트와 신규 테스트를 합쳐 189개가 통과했다.
