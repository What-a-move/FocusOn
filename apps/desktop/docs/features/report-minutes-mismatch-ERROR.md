## 재현 방법

1. 98초·180초 세션이 있는 날 홈과 집중 기록을 연다.
2. 학습 정리 행이 없는 세션의 집중 리포트(`/session-result/?session=ID`)와 노트(`/notes/?session=ID`)를 연다.

## 기대 결과

- 홈·기록·리포트가 같은 분을 보여 준다.
- 정리가 없는 회차는 "정리가 없음"으로 안내한다.

## 실제 결과

- 홈은 오늘 5분·98초 세션 2분, 기록은 오늘 4분·1분으로 보였다.
- 리포트는 "학습 정리 상태를 확인하지 못했어요", 노트는 "학습 노트를 불러오지 못했어요 / 아직 준비 중인 기능이에요"로 보였다.

## 오류 메시지

```text
GET /api/v1/sessions/{id}/learning-summary → 404 NOT_FOUND
```

## 원인 및 해결

- 추정 원인: 서버 리포트 값이 화면마다 다르다.
- 실제 원인: 서버 값은 같았다. 홈(`HomeDashboard.tsx`)만 `Math.round`로 분을 계산했고 기록·리포트는 `Math.floor`였다. 학습 정리 404는 서버 계약상 "정리 행이 없음"인데, Desktop은 API가 없던 때처럼 공통 오류(`NOT_FOUND` → 준비 중)로 처리했다.
- 해결 방법: 홈의 집중 시간을 버림으로 맞췄다(리포트의 계획·흐름 분은 그대로). 리포트·노트에서 학습 정리 `NOT_FOUND`를 "정리 없음" 상태로 따로 보여 준다(오류색 없음).
- 변경 파일: `features/dashboard/HomeDashboard.tsx`, `features/report/SessionResult.tsx`, `features/notes/StudyNote.tsx`
