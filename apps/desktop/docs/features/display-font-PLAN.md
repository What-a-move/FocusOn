## 기능 목적

- 사용자의 문제: 발표 자료·브랜드는 페이퍼로지인데 앱은 Pretendard라 인상이 하나로 맞지 않는다.
- Desktop에서 제공할 가치: 제목·타이머·큰 숫자가 포키·로고와 어울리는 둥글고 힘 있는 글꼴이 된다. 작은 글자는 Pretendard를 그대로 써서 읽기 편한 정도를 지킨다.

## 사용자 흐름

1. 앱을 열면 홈·온보딩·목표·집중·리포트·기록·설정 화면의 큰 글자가 페이퍼로지로 보인다.
2. 본문·버튼·라벨·입력칸·오류 안내는 기존 Pretendard로 보인다.

## Desktop 상세 동작

- 진입 조건: 해당 없음(화면 스타일만 바꾼다)
- 정상 동작: `app/globals.css`에서 `--fo-font-display`를 정의하고 h1·h2와 큰 글자 클래스에만 적용한다.
- 종료 조건: 해당 없음
- 상태 변화: 없음

## macOS 권한 및 시스템 기능

- 필요한 권한: 없음

## 화면 및 사용자 경험

- 적용 대상: h1·h2, 집중 타이머(`.clock`)·목표 문구(`.goal`), 집중 시간 숫자(`.duration-readout strong`), 리포트 큰 시간(`.big-time`), 기록 시간(`.fo-day-time`·`.fo-week-total strong`), 연결 코드 숫자, 목표 설정 말풍선·목표 카드, 학습 노트 제목
- 적용하지 않음: 본문·설명·버튼·라벨·입력칸·오류 안내(20px 미만)
- 글꼴 파일: 페이퍼로지 Bold(600~700)·ExtraBold(800~900) 2종, `public/fonts/`에 넣어 인터넷 없이도 보인다
- 타이머: 페이퍼로지 숫자 폭이 모두 같아(같은 크기에서 0~9 모두 동일) 초가 바뀔 때 흔들리지 않는다
