## 기능 목적

- 흰 카드(문장 + 버튼 두 개)가 일반 알림창처럼 보여 AI 티가 나고 서비스 차별점이 약했다.
- 두더지 캐릭터를 살려, 포키가 강도별 팻말을 들고 나오고 누르면 굴로 '쏙' 들어가게 한다.

## Desktop 상세 동작 (이탈 알림 OFF_TASK만)

- 팻말(AI로 글자까지 그린 이미지): 약하게 `잠깐!`, 보통 `딴짓 감지!`, 적극적으로 `또 놀지?!` (`public/design/poki-sign-*.webp`). 표정은 기존 고개 내민 포키.
- 포키를 누르면 꾹 눌렸다가 굴로 들어감 → `RECENTER`(확인 기록) 뒤 0.45초 애니메이션, `ACK`로 창 닫기. 키보드 Enter도 같다.
- 처음 한 번(이 기기 localStorage)과 포키에 마우스를 올렸을 때만 나무색 안내("포키를 톡! 누르면 돌아가요" + 지금 목표)와 `잠시 쉬기` 버튼을 보여 준다. 포키에서 버튼으로 옮겨 가는 동안 0.9초 유지.
- `잠시 쉬기` 실패 시 안내 자리에 "지금은 멈추지 못했어요"를 보여 준다.
- 대사(`say`·`sub`)는 화면에 그리지 않고 화면 읽기용 숨김 글자로 남긴다.
- 커서: 포키 창은 포커스를 뺏지 않는 패널이라 CSS 커서가 macOS에서 무시된다. 포키·버튼 위에서는 Swift 도우미가 손가락 커서를 직접 지정한다(백그라운드 커서 허용, 결정 042).
- 휴식 제안(BREAK)·연결 끊김(F07)은 기존 카드 그대로.

## 완료 조건 및 결과 (2026-11-13)

- 실제 포키 창(720×380) 빌드 캡처: 강도별·첫 알림·마우스 올림·어두운 배경 확인.
- 화면 흉내 테스트: 누르면 RECENTER → ACK 후 닫힘.
- 사용자 실제 앱 확인: 누르면 쏙, 잠시 쉬기, 포키·버튼 손가락 커서.
- Electron 테스트 189개·tsc·eslint 통과.

## 남은 일·한계

- 손가락 커서는 비공개 CoreGraphics 설정(`SetsCursorInBackground`)에 기대므로 macOS 업데이트로 막힐 수 있다(막혀도 커서만 안 바뀜).
- 휴식 제안(BREAK)용 팻말·포키는 아직 없다.
