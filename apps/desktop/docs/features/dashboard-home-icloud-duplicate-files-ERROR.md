## 오류 제목

- iCloud가 만든 ` 2` 복사본 파일·폴더 때문에 타입 검사와 빌드가 실패함

## 실행 환경

- macOS 버전: Darwin 25.6.0
- Mac 모델·칩: 개발용 Mac (Apple Silicon)
- Electron 버전: 44
- Node.js·pnpm: Next.js 16.3.4, pnpm 11
- 화면 기록 권한: 해당 없음
- 카메라 권한: 해당 없음

## 재현 방법

1. 저장소가 iCloud 동기화 폴더(`~/Desktop`)에 있다.
2. 빌드·개발 서버가 `.next`·`out` 등을 만드는 중 iCloud가 같은 이름의 `... 2` 복사본을 만든다.
3. `tsc --noEmit` 또는 `pnpm build`를 실행한다.

## 기대 결과

- 생성 폴더에 복사본이 없고 타입 검사가 통과한다.

## 실제 결과

- `.next/types/app 2`, `out/... 2` 같은 복사본이 타입 검사 대상에 들어가 중복 선언 오류가 났다. 원본 소스에도 ` 2` 복사본이 생긴 적이 있다.

## 오류 메시지

```text
(중복 선언 오류. 원문은 남아 있지 않다)
```

## 원인 및 해결

- 추정 원인: 빌드 캐시가 깨졌다.
- 실제 원인: 저장소가 iCloud Desktop 동기화 폴더 안에 있어, 파일을 빠르게 다시 쓰는 생성 폴더에서 iCloud가 충돌 복사본(` 2`)을 만든다.
- 해결 방법: 복사본을 지웠다(`find apps -maxdepth 4 -name "* 2*" -not -path "*/node_modules/*" -prune -exec rm -rf {} +`). 원본 소스 복사본은 사용자가 정리했다. 이후 작업마다 빌드 전에 같은 명령으로 확인한다.
- 변경 파일: 없음 (작업 환경)

## 재발 방지 및 남은 작업

- 근본 해결은 저장소를 iCloud 동기화 밖(예: `~/dev`)으로 옮기거나 Desktop 폴더 동기화를 끄는 것이다. 옮기기 전까지는 빌드 전에 복사본을 확인한다.
