# 집중 준비 - 직접 입력 줄바꿈 오류

## 증상
집중 준비 화면에서 「직접」을 고르면, 창 너비가 약 900~1000px일 때 `− 300 + 5~300분` 줄이 "5시간 …까지" 아래로 내려가 왼쪽에 붙었다.

## 실제 원인 (측정함)
`.duration-row`에 `flex-wrap: wrap`이 걸려 있었다. 창 910px 기준 측정값은 다음과 같다.
- 줄 너비 491px
- 시간 표시 204px + 간격 20px + 직접 입력 270px = 494px

3px가 모자라 직접 입력 줄 전체가 다음 줄로 넘어갔다.

## 고친 방법
- `.duration-row`의 wrap을 없앴다.
- `.custom-row`에 `flex-shrink: 0`을 줘서 직접 입력 줄은 항상 오른쪽 한 줄에 둔다.
- `.duration-readout`에 `flex-wrap: wrap`과 `min-width: 0`을 줬다. 공간이 모자라면 "…까지"만 큰 숫자 아래로 내려간다.

## 확인
40, 100, 300분으로 확인했다. 모든 창 크기에서 직접 입력 줄이 내려가지 않았고 가로 넘침도 없었다.

| 창 크기 | "…까지" 위치 |
| --- | --- |
| 1200×768 | 숫자 옆 |
| 910×700 | 숫자 아래 |
| 800×600 | 숫자 옆 (한 단 레이아웃) |
