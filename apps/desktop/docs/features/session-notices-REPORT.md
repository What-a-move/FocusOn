# Desktop 집중 중 안내 결과

## 기본 정보

- 담당 영역 및 앱은 Frontend Desktop이다.
- 작업 브랜치는 `feat/desktop-session-notices`다.
- 검증일은 2026-11-25다.

## 구현 결과

- 오프라인, 사용자가 제외한 앱, 민감한 화면, 동의한 카메라 사용 불가를 집중 화면에 표시한다. 안내가 겹치면 오프라인, 화면, 카메라 순으로 표시한다.
- 전경 앱이 바뀌면 안내를 바로 갱신한다. OCR에서 민감한 화면을 찾으면 서버 응답 전에 보호 상태를 표시한다.
- 세션 런타임이 기존 IPC로 안내 상태를 넘기고, 집중 화면은 타이머와 함께 말풍선을 표시한다.

## 검증

- [x] macOS 26.6.1 arm64에서 Electron 44.1.0 기동 및 Preload 연결
- [x] Electron 테스트 210개, TypeScript 검사, ESLint 오류 0건
- [x] 로컬 Chrome에서 가짜 IPC 응답으로 안내 4종, 제외 목록 링크, 안내 해제 확인
- [ ] 실제 계정으로 집중을 시작한 뒤 네트워크, 전경 앱, 카메라 상태 변경과 복구 확인

## 남은 범위

- Chrome 제외 사이트 및 민감 페이지 상태와 세션 중 알림 권한 상태에는 Desktop이 받을 신호가 필요하다.
