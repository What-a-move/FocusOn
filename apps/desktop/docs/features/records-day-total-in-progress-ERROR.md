2. `/records/`에서 오늘을 고른다.

## 기대 결과

- 하루 총합과 회차 수는 서버가 종료 확정 세션만으로 계산한 값(`totalActiveMs`)이다. 진행 중 회차는 목록에만 `진행 중`으로 보인다(Notion 리포트 설계서 2.2).

## 실제 결과

- 화면이 `sessions[]` 카드의 시간을 직접 더해 진행 중 회차까지 총합과 회차 수에 들어갔다.

## 오류 메시지

```text
오류 메시지 없음 (표시값 불일치)
```

## 원인 및 해결

- 추정 원인: 수정 당시 기록하지 않았다(사후 작성).
- 실제 원인: 하루 응답의 `totalActiveMs` 대신 `sessions[]`를 화면에서 다시 합산했다. 일간 응답의 `endedAt`이 `string | null`이라 진행 중 카드가 섞일 수 있는데, 이 카드를 걸러내지 않았다.
- 해결 방법: 총합은 서버 `totalActiveMs`를 그대로 쓰고, 회차 수는 `endedAt`이 있는 회차만 센다.
- 변경 파일: `features/records/Records.tsx`, `docs/features/records-PLAN.md`
