# Desktop 이탈 전 미리 알림

- 담당: Frontend (`apps/desktop`)
- 우선순위: MVP 기본
- 관련 이슈: [#395](https://github.com/What-a-move/FocusOn/issues/395)
- 작업 브랜치: `codex/395-desktop-pre-reminder`
- 정본: [리포트 설계서 C](https://app.notion.com/p/3de0b6e5e64c808683b0e9a4a79fccca), `settings.html#goals`, `session.html?notify=reminder`
- 선행: PR #388 첫 이탈 판정, PR #393 목표·기록 설정 탭

## 사용자 흐름

1. 설정 → 목표·기록에서 미리 알림을 켜거나 끈다. 기본값은 켜짐이다.
2. 최근 종료 회차 최대 5개에서 일시정지를 제외한 첫 이탈까지의 집중 시간을 계산한다. 유효한 첫 이탈이 3개 이상일 때만 중간값을 사용한다.
3. 중간값 3분 전, 집중 중일 때 macOS 알림을 회차당 최대 한 번 보낸다. 클릭하면 같은 회차의 집중 화면으로 돌아간다.

## 데이터와 예외

- 기존 집중 설정 GET/PUT과 세션 목록·요약·분석 기록·일시정지 GET을 사용한다.
- 기록이 부족하면 설정에 안내한다. 조회 실패는 부재와 구분하고, 알림은 생략한다.
- 중간값이 3분 이하이거나 예정 시각을 이미 지났으면 알림을 생략한다.
- 집중 중에만 시간을 세고 알림 권한이 없거나 설정이 꺼진 경우 표시하지 않는다.
- 화면 원문·URL·회차 내용을 추가로 저장하지 않는다. 재시작 후 중복 방지를 위해 최근 알림 식별값의 해시만 로컬에 남긴다.
