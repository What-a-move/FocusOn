## 오류 제목

- F07 포키의 `앱 열기`를 눌러도 FocusOn 메인 창이 앞으로 오지 않음

## 실행 환경

- macOS 버전: 26.6.1 (Darwin 25.6.0)
- Mac 모델·칩: Apple M4
- Electron 버전: 44.1.0 (개발 실행)
- Node.js·pnpm: 개발 실행
- 화면 기록 권한: 허용
- 카메라 권한: 해당 없음

## 재현 방법

1. 다른 앱을 쓰는 중에 F07 포키가 뜨게 한다(포키 창은 FocusOn을 활성화하지 않는 패널).
2. `앱 열기`를 누른다.

## 기대 결과

- FocusOn 메인 창이 맨 앞에 나타난다.

## 실제 결과

- 포키는 닫혔지만 메인 창은 `document.visibilityState: hidden` 그대로.

없음

## 원인 및 해결

- 추정 원인: 포키 창 IPC가 F07 동작(`OPEN_APP`)을 받지 못한다.
- 실제 원인: 추정과 달랐다(포키는 닫힘 = IPC 정상). macOS에서는 비활성 앱의 창에 `show()`·`focus()`만 해서는 앱이 앞으로 오지 않는다. 포키 창이 일부러 FocusOn을 활성화하지 않는 패널이라 앱이 계속 비활성 상태였다.
- 해결 방법: 사용자가 누른 `앱 열기`에서만 `app.focus({ steal: true })`로 앱을 활성화한 뒤 메인 창을 보여 준다.
- 변경 파일: `electron/main/index.cts`

## 확인 결과

- [x] 같은 방법으로 재현되지 않는다. (메인 창 `visible`, `hasFocus: true`)
- [ ] 권한 허용·거부 양쪽을 확인했다. (해당 없음)
- [x] 앱 재실행 후 정상 동작한다.
- [x] 관련 기능의 회귀가 없다. (포키가 뜰 때는 여전히 맨 앞 앱을 바꾸지 않음)

## 재발 방지 및 남은 작업

- 포커스를 빼앗지 않는 창에서 앱을 여는 동작은 앱 활성화까지 확인한다. 자동으로 뜨는 동작에는 `steal`을 쓰지 않는다.
