## 기능 목적

- 사용자의 문제: 고민·응원·기본 포키가 오류·빈 화면·온보딩에 반복돼, 오류인데 "궁금해하는" 표정이 나오는 등 상황이 잘 전달되지 않는다.
- Desktop에서 제공할 가치: 상황마다 다른 포키(걱정·두리번·쓰는 중·빈 공책·알람·생각·축하·플러그·동의·열쇠)로 한눈에 상태를 알 수 있다.

## 사용자 흐름

1. 오류·빈 화면·온보딩·설정·리포트·학습 노트·집중 화면에서 상황에 맞는 포키가 보인다.
2. 문구·버튼·동작은 그대로다.

## Desktop 상세 동작

- 진입 조건: 해당 없음(이미지 경로만 바꾼다)
- 상태 변화: 없음

## 화면 및 사용자 경험

| 상황 | 포키 |
|---|---|
| 불러오기 실패(`LoadError` 기본), 집중 상태 불러오기 실패, 화면 기록 권한 꺼짐, 노트 정리 실패 | `poki-worried` |
| `NOT_FOUND`, 기록 없음, 리포트·노트 없음, 진행 중인 집중 없음 | `poki-looking` |
| 노트 정리 준비·진행 중 / 내용 부족 | `poki-writing` / `poki-empty-note` |
| 목표한 시간이 지났어요 | `poki-time-up` |
| 목표 질문·후보, 자동 종료 리포트, 집중 끝내기 확인 | `poki-thinking` |
| 리포트 완료, 온보딩 완료, 목표 확정, 설정 계정 | `poki-celebrate` |
| 온보딩 Chrome 연결, 설정 기기 연결 | `poki-plug` |
| 온보딩 동의 / 권한, 설정 분석·권한 | `poki-consent` / `poki-key` |

- 얼굴 규칙: 입 없음, 눈썹은 눈에 붙이거나 눈웃음·일직선 눈.
- 유지: 집중 달력·프로필 얼굴(기존 포키 잘라 쓰기), 화면 위 포키 알림(#174), 집중 설정 알림 강도 미리보기, 닉네임 단계.
