# 세션 할 일과 목표 프로필

## 기본 정보

- 기능명: 세션 할 일과 목표 프로필
- 기능 ID: DR-024, DR-030
- 담당 영역: Frontend
- 대상 앱: Desktop
- 관련 Issue: #298, #313, #319
- 예정 Branch: codex/319-goal-profile-session-goals

## 기능 목적과 사용자 흐름

1. 목표 확인 화면에서 AI가 제안한 핵심 주제·보조 주제·예상 활동을 검토하고 수정해 저장한다.
2. 집중 준비 화면에서 저장한 할 일을 최대 3개까지 골라 시작한다.
3. 집중 중에는 현재 세션에 담은 할 일을 확인하고, 이미 저장한 다른 할 일을 추가할 수 있다.

## 화면 및 데이터

- 목표·세션 화면의 기존 구조, 디자인 토큰과 접근 가능한 기본 입력을 재사용한다. 새 화면 전용 디자인 원본은 확인할 수 없었다.
- Main IPC에서 목표 프로필과 할 일 ID를 검증한다. 분석 API가 제목만 보고 관련 학습이라고 판단해도 할 일과 맞지 않으면 네이티브 OCR 확인 절차를 적용한다.
- 분석 일정, 카메라, 화면 기록 권한, 민감 정보 차단 규칙은 기존 동작을 유지한다.
