# 포키 흐림 오버레이가 불투명하게 표시됨

- 기능: 강도별 포키 딴짓 알림
- 관련 이슈: [#282](https://github.com/What-a-move/FocusOn/issues/282)
- 발생 일시: 2026-11-19
- 대상: macOS 노치 내장 화면, Electron 44.1.0
- 상태: 해결

## 재현과 실제 결과

`under-window` vibrancy를 기본 효과 상태로 둔 비활성 투명 패널 위에 갈색 반투명 색을 칠했다. 전체 화면 앱과 일반 Space에서 뒤 화면의 색과 형태가 사라지고 거의 단색으로 보였다.

## 원인 및 해결

- 추정 원인: CSS 반투명 색이 뒤 화면을 가렸을 가능성을 확인했다.
- 실제 원인: 같은 반투명 색이더라도 macOS가 합성한 바탕 재질과 효과 상태에 따라 뒤 화면을 비추는 방식이 달랐다. 초기 `under-window`와 기본 상태 조합에서 단색이 발생했다. 재질과 효과 상태 각각의 영향은 분리 측정하지 않았다.
- 해결: 투명 배경색을 명시하고 `hud` vibrancy를 `active` 상태로 사용했다. 약한 흐림과 강한 흐림은 그 위 색의 투명도를 .22와 .38로 구분한다.

## 확인 결과

서로 다른 프로세스의 전체 화면 앱과 일반 Space에서 뒤 화면의 모양이 흐리게 비쳤다. 오버레이는 포커스를 가져오지 않았다.
