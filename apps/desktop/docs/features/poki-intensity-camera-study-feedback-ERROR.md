# 카메라 알림에서 공부 표시 안내가 노출됨

- 기능 F04, Desktop, 2026-11-19, #282
- 상태 해결

## 재현과 기대 결과

카메라에서 온 적극 알림을 띄우고 카운트다운이 끝날 때까지 기다린다. 기존 흐름은 ‘이것도 공부야’ 버튼과 클릭 뒤 ‘다음 분석에 반영할게요’ 안내를 표시했다. 카메라 팝업은 포키나 팻말 클릭으로 닫히는 것이 기대 동작이다.

## 원인 및 해결

- 추정 원인 — 카메라와 서버 알림에 같은 공부 표시 화면이 쓰인다고 봤다.
- 실제 원인 — Main은 카메라 ID를 확인해 서버 기록을 건너뛰지만, `OffTaskAlert`는 알림 출처를 구분하지 않고 공부 버튼과 토스트를 렌더링했다.
- 해결 — 카메라 ID의 공부 버튼과 토스트를 숨긴다. 기존 카운트다운과 포키·팻말의 닫기 동작을 유지한다.
