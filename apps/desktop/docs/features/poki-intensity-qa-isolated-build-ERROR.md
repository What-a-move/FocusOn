# 포키 캡처용 분리 빌드에서 계약 타입 누락

- 기능: 강도별 포키 딴짓 알림
- 관련 이슈: [#282](https://github.com/What-a-move/FocusOn/issues/282)
- 발생 일시: 2026-11-19
- 환경: macOS 26.6.1, Next.js 정적 빌드
- 상태: 해결

## 재현과 실제 결과

환경 파일 없이 화면을 빌드하려고 임시 경로에 앱 일부를 복사했다. webpack 컴파일 뒤 타입 검사에서 `electron/shared/session-contract.cjs`를 찾지 못해 빌드가 실패했다.

## 원인 및 해결

- 추정 원인: 임시 경로에서 연결된 패키지를 찾지 못했다고 봤다.
- 실제 원인: Renderer가 타입 검사에 사용하는 Electron 계약 소스 디렉터리를 임시 빌드에서 빠뜨렸다.
- 해결: 임시 빌드에 `electron/` 소스를 포함했다. 환경 파일을 복사하지 않은 상태에서 `/floating`을 포함한 정적 빌드를 확인했다.
