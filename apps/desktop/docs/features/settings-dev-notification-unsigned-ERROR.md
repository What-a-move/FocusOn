## 오류 제목

- 개발 실행에서 시험 알림이 뜨지 않고 macOS 알림 목록에 `Electron`이 생기지 않는다. 화면은 보냄으로 처리한다.

## 실행 환경

- macOS 버전: 26.6.1
- Mac 모델·칩: Apple M4
- Electron 버전: 44.1.0 (adhoc 서명, 이 Mac의 코드 서명 인증서 0개)
- Node.js·pnpm: 24.14.1 · 11.19.0
- 화면 기록 권한: 허용
- 카메라 권한: 해당 없음

## 재현 방법

1. 개발 실행한 앱의 온보딩 권한 화면에서 `시험 알림 보내기`를 누른다.
2. 시스템 설정 › 알림에서 `Electron`을 찾는다.

## 기대 결과

- 허용을 묻는 창이 뜨고 알림 목록에 앱이 생긴다. 실패하면 화면에 실패를 알린다.

## 실제 결과

- 알림이 뜨지 않고 목록에 앱이 없다. 화면은 성공(`shown: true`)으로 처리한다.

## 오류 메시지

```text
알림 하나만 보내는 Electron 테스트 앱(open -a로 실행):
supported=true
failed=작업을 완료할 수 없습니다.(UNErrorDomain 오류 1.)
```

## 원인 및 해결

- 추정 원인: 집중 모드 또는 알림 설정에서 앱을 꺼 두었다.
- 실제 원인: `UNErrorDomain 1`은 알림이 허용되지 않았다는 뜻이다. 개발용 `Electron.app`은 adhoc 서명이라 macOS가 허용 창 없이 거절하고 알림 목록에도 등록하지 않는다. 또 `permission-ipc.cts`의 시험 알림은 `Notification`의 `failed` 이벤트를 듣지 않고 항상 `shown: true`를 돌려준다.
- 해결 방법: 이번 QA는 시험 알림을 확인 불가로 기록했다. 실제 확인은 서명된 빌드(Apple Development 인증서 이상)로 한다. 실패를 화면에 알리는 수정은 오류 문구 개선 작업에서 한다.
- 변경 파일: 없음
