# Desktop 기능 기획서

## 기본 정보

- 기능명: 할 일 고르기 · 목표 확인
- 대상 앱: Desktop
- 디자인 원본: `FocusOn-design/todo-goals.html` (`?view=pick`, `?view=review`)
- 작성일: 2026-11-24
- 작성자: jae1
- 관련 PR: #329 (#328 공통 토큰 위)
- 서버 의존: `GET /goals?todoStatus=OPEN` (목록 + `goalProfile`), `POST /sessions` `goalIds` (#313·#316·#327 병합됨)

## 기능 목적

- 집중 시작을 "목표 한 줄 적기"에서 "적어 둔 할 일 중 최대 3개 고르기"로 바꾼다.
- 고른 할 일마다 AI가 넓혀 둔 범위(핵심 주제·함께 보는 주제·하게 될 활동)를 시작 전에 보여 준다.

## 사용자 흐름

1. 홈 `할 일 고르기` · 사이드바 `집중 시작` · 집중 기록 빈 화면 → `/todo/`
2. 할 일 카드에서 최대 3개 선택 (고른 순서 = 1·2·3 금색 배지) → `N개로 시작`
3. 목표 확인: 할 일마다 넘겨 보는 범위 슬라이드 → 마지막에서 `시간 정하기`
4. 집중 준비: 고른 할 일 요약 + `바꾸기`(→ `/todo/`) → 시간·알림 정하고 시작
5. `새 할 일 적기` → 목표 설정(`/goal/`) → 저장 후 `/todo/`로 돌아와 새 할 일이 골라진 채로 보임

## Desktop 상세 동작

- 고른 할 일은 `sessionStorage` `focuson.confirmedGoal`에 `{goalId, goalText}[]`로 넘긴다(`readPicked`, 최대 3).
- 목록을 다 받은 뒤 목록에 없는(닫힌) 할 일은 고른 것에서 뺀다.
- 집중 준비에 고른 할 일 없이 들어오면 `/todo/`로 보낸다.
- 목표 확인은 ←·→ 키, 화살표 버튼, 위 할 일 탭으로 넘긴다.
- 로그아웃 이벤트를 받으면 홈으로 보낸다.

## 화면 및 사용자 경험

- 상태: 불러오는 중 / 빈 목록(할 일 적기) / 불러오기 실패(다시 시도) / 더 보기 / 3개 가득(나머지 카드 흐림)
- 목표 확인: 범위가 없거나 형식이 어긋나면 `범위를 만들지 못했어요. 할 일 이름만 보고 판단할게요.`
- 공통 여백·할 일 금색 토큰(`--fo-todo-1..3`)을 쓴다.

## 데이터 및 IPC/API

- `goal:listOpen` 응답 항목에 `goalProfile`(선택)을 함께 넘긴다. 형식이 어긋나면 범위만 버리고 할 일은 남긴다(`parseCreatedGoal`).

## 예외 처리

- 목록 실패: 전체 실패는 가운데 오류 화면, 다음 페이지 실패는 목록 아래 한 줄.
- 저장소를 못 쓰면 집중 준비가 할 일 고르기로 돌려보낸다.

## 보안·개인정보

- 할 일 문구·id만 `sessionStorage`에 둔다. 범위는 화면에만 쓰고 저장하지 않는다.
