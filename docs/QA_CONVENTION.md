# QA 규칙

## 공통 확인

- 정상 흐름이 동작한다.
- 빈 값, 잘못된 값, 중복 요청을 처리한다.
- 네트워크 오류와 서버 오류를 사용자에게 안내한다.
- 권한 거부 후에도 앱이 비정상 종료되지 않는다.
- 분석 제외 대상에서 분석이 실행되지 않는다.
- 민감한 값이 화면·로그·에러 메시지에 노출되지 않는다.

## Desktop 확인

- macOS 앱이 실행된다.
- 활성 앱 확인이 정상 동작한다.
- 화면 캡처 권한이 없을 때 안내한다.
- 타이머 시작·일시정지·재개·종료가 정확하다.
- 휴식 알림 후 사용자의 선택이 반영된다.
- 카메라 동의 여부에 따라 카메라 분석이 분리된다.

## Extension 확인

- Extension이 설치되고 팝업이 열린다.
- 현재 탭 정보와 페이지 이동이 기록된다.
- 제외 도메인에서는 콘텐츠 분석이 실행되지 않는다.
- 페이지 이동 후 설정된 시간에 재분석된다.
- Desktop과의 연결이 끊겨도 오류를 안내한다.

## PR 전 체크

- [ ] 관련 기능을 직접 실행했다.
- [ ] 예외 상황을 확인했다.
- [ ] 기존 기능의 회귀 여부를 확인했다.
- [ ] 결과 리포트를 작성했다.
- [ ] 문서와 코드가 일치한다.
