# FocusOn 시스템 아키텍처

## 구성

```text
사용자
  ↓
  Desktop App (Electron + Next.js + React)
  ├─ macOS 활성 앱 확인
  ├─ 화면 캡처 및 학습 세션 제어
  ├─ MediaPipe 카메라 분석 결과 수신
  └─ 집중 상태·알림·리포트 표시
       │
       ├──────── Chrome Extension (Next.js + React)
       │             ├─ 현재 탭·페이지 제목 확인
       │             ├─ 페이지 이동 흐름 기록
       │             └─ 콘텐츠 분석용 데이터 전달
       │
       └──────── Spring Boot Server
                     ├─ 회원·목표·세션·설정 관리
                     ├─ 분석 이벤트 저장
                     └─ AI 서비스 연결
                                  │
                                  └─ AI Service
                                      ├─ 화면·페이지 관련성 판단
                                      ├─ 집중 상태 보조 판단
                                      └─ 분석 결과 반환
```

## 영역별 책임

### Desktop

- 학습 세션 시작·중지·종료
- 타이머와 휴식 알림
- macOS 활성 앱 확인
- 분석 제외 앱 처리
- 화면 캡처 권한과 캡처 생명주기 관리
- 카메라 권한 요청 및 MediaPipe 결과 표시

### Chrome Extension

- 현재 탭, URL, 페이지 제목 확인
- 페이지 이동 이벤트 수집
- 일정 시간 머문 페이지의 재분석 요청
- 분석 제외 도메인 처리
- Desktop과 브라우저 상태 전달

### Spring Boot Server

- 사용자, 목표, 설정, 세션 데이터 관리
- Desktop·Extension·AI 사이의 인증 및 API 제공
- 이벤트 저장과 리포트 조회
- 개인정보 및 보존 기간 정책의 서버 측 적용

### AI Service

- 화면 또는 페이지에서 전달된 텍스트·메타데이터 분석
- 사용자의 학습 목표와 현재 활동의 관련성 판단
- 판단 결과와 신뢰도 반환
- 원본 화면이나 카메라 영상을 기본 저장하지 않음

## 집중 상태

| 상태 | 의미 |
| --- | --- |
| `FOCUSED` | 목표와 관련된 활동이 확인됨 |
| `UNCERTAIN` | 판단할 정보가 부족함 |
| `DISTRACTED` | 목표와 관련성이 낮은 활동이 확인됨 |
| `PAUSED` | 사용자가 타이머 또는 분석을 중지함 |
| `EXCLUDED` | 사용자가 분석 제외 대상으로 설정함 |
