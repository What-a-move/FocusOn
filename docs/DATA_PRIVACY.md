# 데이터 처리 기준

이 문서는 개발 단계에서 지켜야 할 내부 기준이다. 법률 검토를 거친 개인정보 처리방침을 대신하지 않는다.

## 수집 대상

- 계정 식별 정보
- 사용자가 입력한 학습 목표와 설정
- 학습 세션의 시작·종료·일시정지 기록
- 현재 앱 이름, 앱 식별자, 브라우저 도메인, 페이지 제목
- 화면 분석에 필요한 텍스트 또는 분석 결과
- 사용자가 동의한 경우 카메라에서 계산된 시선·자세 상태값
- Desktop·Extension 연결을 위한 기기 식별자와 일회용 연결 코드의 상태

## 기본 원칙

- 카메라 사용은 명시적인 사용자 동의 후에만 시작한다.
- 원본 카메라 영상은 기본적으로 저장하거나 전송하지 않는다.
- 원본 화면 캡처도 기본 저장하지 않고 분석에 필요한 최소 데이터만 사용한다.
- 사용자가 지정한 제외 앱과 도메인은 해당 화면의 캡처·DOM·OCR·AI 콘텐츠 분석을 즉시 중지하고 타이머를 유지한다. 최신 제외 상태가 확인된 `EXCLUDED`에서 별도 카메라 동의·권한이 유효하면 로컬 카메라 분석만 계속할 수 있다. 최신 제외 상태를 확인할 수 없거나 `PRIVACY_BLOCKED`, 카메라 동의 철회 상태에서는 카메라 분석도 즉시 중지한다.
- 비밀번호, API Key, 인증 토큰은 로그와 문서에 기록하지 않는다.
- 수집 목적과 무관한 데이터는 저장하지 않는다.
- 일회용 연결 코드는 짧은 유효 시간 후 폐기하고, 인증 토큰은 문서·로그에 남기지 않는다.
- 두더지 마스코트의 문구·표정 선택은 분석 원본이 아니라 분석 결과를 사용자에게 표현하는 UI 설정으로 취급한다.

## 제외 대상 처리

```text
현재 활성 앱 또는 도메인 확인
  ↓
제외 목록과 비교
  ↓
최신 상태 확인 불가 → 상태 확인까지 화면·카메라 분석 중지
  ↓
일치하면 화면 캡처·DOM·OCR·AI 콘텐츠 분석 중지 (`EXCLUDED`), 타이머 유지
  ↓
별도 카메라 동의·권한이 유효한 경우에만 로컬 카메라 분석 허용
  ↓
민감 화면·권한 불명·동의 철회 등 `PRIVACY_BLOCKED`이면 카메라도 중지
```

- Extension이 제외 도메인을 확인하면 페이지 본문 수집과 분석 요청을 즉시 중지한다.
- 제외 상태가 Server를 통해 Desktop에 반영되면 Desktop도 같은 세션의 화면 캡처·DOM·OCR·AI 콘텐츠 분석을 중지한다. 최신 상태를 확인할 수 없는 동안은 카메라도 중지하고, 확인된 `EXCLUDED`에서만 별도 동의·권한을 확인해 로컬로 계속할 수 있다.
- 네트워크 단절 등으로 Desktop이 최신 도메인 제외 상태를 확인할 수 없으면 안전한 상태가 확인될 때까지 화면 콘텐츠 분석과 카메라 분석을 중지한다. 화면 분석은 제외 여부를 확인한 뒤 재개한다.
- 제외 도메인을 벗어나도 현재 활성 도메인과 세션 상태를 다시 확인하기 전에는 분석을 재개하지 않는다.
- 제외된 화면·페이지 원본은 임시 저장하거나 나중에 재전송하지 않는다. 카메라 원본은 제외 여부와 무관하게 저장·전송하지 않고, 분석 중 프레임은 기기 메모리에서만 처리한다.

## 로그 기준

로그에는 요청 시각, 기능명, 오류 코드, 민감 정보를 제거한 요청 추적 ID만 남기는 것을 기본으로 한다. URL 전체와 Query, 화면·페이지 본문, 카메라 원본, 개인 메시지 내용은 디버깅 상황에서도 기록하지 않는다. 문제 분석에는 본문 길이, 수집 성공 여부, 분석 결과 코드처럼 원문을 복원할 수 없는 최소 정보만 사용한다.

## MVP 보관 기간

| 데이터 | 구현 기준 |
| --- | --- |
| 세션 이력·요약·일간 리포트·복습 노트 | 세션 종료 후 1년 |
| 분석 실행·학습 정리 근거 | 세션 종료 후 90일 |
| token family·pairing code | 폐기·만료 후 30일 |
| 동의 이력 | 철회 또는 계정 삭제 후 3년 |
| 보안 감사 로그 | 생성 후 180일 |
| 백업 | 생성 후 최대 35일 |
| 탈퇴 계정 | 운영 DB에서 30일 이내 삭제 또는 익명화 |

raw DOM·OCR·스크린샷·카메라 프레임·얼굴 landmark는 보관 기간과 무관하게 영구 저장하지 않는다. 위 기간은 MVP 구현 기준이며 법률 검토가 필요한 변경안은 별도로 표시한다.
