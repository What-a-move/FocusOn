# 데이터 처리 기준

이 문서는 개발 단계에서 지켜야 할 내부 기준이다. 법률 검토를 거친 개인정보 처리방침을 대신하지 않는다.

## 수집 대상

- 계정 식별 정보
- 사용자가 입력한 학습 목표와 설정
- 학습 세션의 시작·종료·일시정지 기록
- 현재 앱 이름, 앱 식별자, 브라우저 도메인, 페이지 제목
- 화면 분석에 필요한 텍스트 또는 분석 결과
- 사용자가 동의한 경우 카메라에서 계산된 시선·자세 상태값
- Desktop·Extension 연결을 위한 기기 식별자와 일회용 연결 코드의 상태

## 기본 원칙

- 카메라 사용은 명시적인 사용자 동의 후에만 시작한다.
- 원본 카메라 영상은 기본적으로 저장하거나 전송하지 않는다.
- 원본 화면 캡처도 기본 저장하지 않고 분석에 필요한 최소 데이터만 사용한다.
- `EXCLUDED` 앱·도메인은 화면 캡처·OCR·화면 AI 분석과 화면 근거 알림을 즉시 중지한다. 유효한 사용자 동의가 있는 카메라 분석은 별도 정책에 따라 계속할 수 있다.
- `PRIVACY_BLOCKED`, 카메라 동의 철회, 세션 일시정지·종료는 카메라 스트림과 화면·카메라 분석을 모두 중지한다.
- 비밀번호, API Key, 인증 토큰은 로그와 문서에 기록하지 않는다.
- 수집 목적과 무관한 데이터는 저장하지 않는다.
- 일회용 연결 코드는 짧은 유효 시간 후 폐기하고, 인증 토큰은 문서·로그에 남기지 않는다.
- 두더지 마스코트의 문구·표정 선택은 분석 원본이 아니라 분석 결과를 사용자에게 표현하는 UI 설정으로 취급한다.

## 제외 대상 처리

```text
현재 활성 앱 또는 도메인 확인
  ↓
제외 목록과 비교
  ↓
일치하면 화면 캡처·OCR·화면 AI 분석·화면 근거 알림 중지
카메라는 별도 동의가 유효하면 분석 계속 가능
개인정보 차단(PRIVACY_BLOCKED) 또는 동의 철회면 화면·카메라 모두 중지
  ↓
제외 상태만 기록하거나 기록 자체를 생략
```

- Extension이 제외 도메인을 확인하면 페이지 본문 수집과 분석 요청을 즉시 중지한다.
- `EXCLUDED` 상태가 Server를 통해 Desktop에 반영되면 Desktop은 화면 캡처·OCR·AI와 화면 근거 알림을 중지한다. 카메라 분석은 별도 동의가 유효할 때만 계속할 수 있다.
- `PRIVACY_BLOCKED`이거나 카메라 동의 상태를 확인할 수 없으면 화면·카메라 분석을 모두 중지한다. 네트워크 단절 등으로 제외 상태를 확인할 수 없을 때도 안전한 상태가 확인될 때까지 분석을 재개하지 않는다.
- 제외 도메인을 벗어나도 현재 활성 도메인과 세션 상태를 다시 확인하기 전에는 분석을 재개하지 않는다.
- 제외된 화면·페이지 원본은 임시 저장하거나 나중에 재전송하지 않는다. 카메라 프레임은 동의 상태와 무관하게 저장·전송하지 않으며, 분석 중단 시 스트림을 해제한다.

## 로그 기준

로그에는 요청 시각, 기능명, 오류 코드, 민감 정보를 제거한 요청 추적 ID만 남기는 것을 기본으로 한다. URL 전체와 Query, 화면·페이지 본문, 카메라 원본, 개인 메시지 내용은 기본적으로 기록하지 않는다. 문제 분석에는 본문 길이, 수집 성공 여부, 분석 결과 코드처럼 원문을 복원할 수 없는 최소 정보만 사용한다.

로컬 수동 테스트에서만 예외적으로, 개발자가 직접 입력한 비민감 목표 query를 LangSmith에 표시할 수 있다. 이 예외는 `LANGSMITH_TRACE_RAW_GOAL_TEXT=true`를 명시한 경우에만 적용하며, 공유·통합·배포 환경에서는 반드시 `false`여야 한다. 실제 사용자 입력, 화면·페이지 본문, 카메라 원본, 인증 정보는 이 예외의 대상이 아니다. 서비스화 전에는 이 예외를 제거하거나 별도 승인된 관측 정책으로 대체한다.
