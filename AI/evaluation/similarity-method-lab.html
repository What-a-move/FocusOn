학습 화면과 게임 화면 비교

동일한 두 개의 JSON 입력을 1~7번 관련성 판정 방식에 넣어 내부 콘텐츠 판정, 공개 relevanceLabel, 점수, 반환 텍스트와 브라우저 실행 시간을 확인합니다.

실험용 계산: 3·4·6·7번의 벡터는 글자 조각으로 만든 대역이며 실제 임베딩·재정렬 모델을 호출하지 않습니다. 5~7번의 Graph도 JSON 개념 목록으로 흉내 낸 관계입니다. 점수는 방식별 유사도 신호이며 정답 확률이나 신뢰도가 아닙니다. 두 사례의 정답률과 브라우저 실행 시간으로 방식을 확정할 수 없습니다. 게임 화면의 내부 OFF_TASK는 한 번의 화면 관찰만으로 공개 UNRELATED나 이탈 알림이 되지 않습니다.

입력 JSON

평가용 구조입니다. expectedContentRelation은 내부 콘텐츠 판정의 정답이고 expectedRelevanceLabel은 공개 값의 기대값입니다. 두 필드는 평가용이며 실제 분석 입력에는 들어가지 않습니다. 목표와 개념, 사례를 아래에서 수정할 수 있습니다.
