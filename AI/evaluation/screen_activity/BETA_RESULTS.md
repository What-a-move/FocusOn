# 10,168건 화면 활동 모델 베타 평가

팀원 무알림 베타에서는 10,168건으로 학습한 단일 분류기를 사용한다. 반복 비교에 사용한 Chrome 22개와 캔버스 19개에서 총 **29/41(70.7%)**을 맞혔다. 팀원의 실제 공부 시간당 오알림은 아직 측정하지 않았다.

## 평가 방법

각 화면에서 현재 Chrome 탭의 메타데이터를 먼저 넣고, 추가 근거가 필요하면 해당 탭의 DOM을 넣어 최종 판정을 비교했다. Chrome OCR은 사용하지 않았다. 상위 두 점수 차이가 1%p 이하이거나 확정 점수가 0.60 미만이면 보류한다. 메타데이터 단계의 딴짓 후보는 본문을 확인한다. 41개는 개발 과정에서 여러 번 비교한 고정 화면이며 실제 사용 빈도를 반영한 무작위 표본이 아니다. 이번 수치는 데스크톱 Apple Vision OCR의 정확도를 포함하지 않는다.

## 실제 Chrome 화면 22개

**19/22(86.4%)**. 공부 6/6, 딴짓 5/6, 보류 8/10을 맞혔다. 18개에서 DOM을 요청했다. 부스트코스는 공부로 판정했다. [22개 화면별 첫 판정과 최종 판정](data/beta-chrome22-results.json)

- Dailymotion의 오락 추천 피드는 딴짓이었지만 DOM을 읽은 뒤에도 보류했다.
- 빈 DrawIsland 그림 도구는 보류가 정답이었지만 DOM을 읽은 뒤 딴짓으로 판정했다.
- HackMD 기능 소개는 보류가 정답이었지만 탭 제목만으로 공부로 판정해 DOM을 요청하지 않았다.

## 캔버스 화면 19개

캔버스는 웹 브라우저 안에서 그림을 그리거나 도형·회로를 배치하는 작업 영역이다. 게임도 같은 방식으로 화면을 그릴 수 있다. 캔버스 평가 19개는 게임 5개와 학습 도구 7개의 빈 화면·작업 화면 14개로 구성했다.

**10/19(52.6%)**. 게임 3/5와 빈 화면 7/7을 맞혔다. 실제 작업 화면 7개는 모두 보류했다. Simple Canvas Game, Net 퍼즐, London 2012 Basketball은 딴짓으로 잡았고 Javascript Racer와 Radius Raid는 보류했다. [19개 화면별 첫 판정과 최종 판정](data/beta-canvas19-results.json)

7개 도구를 새 Chrome 프로필에서 직접 조작해 다시 수집했다. 각 도구 안에서 빈 화면과 작업 화면의 탭 메타데이터와 정제된 DOM 본문이 완전히 같았다. 모두 메타데이터에서 보류하고 DOM을 읽은 뒤에도 보류했다.

- GeoGebra에 삼각형을 그리고, Ray Optics에 광원과 거울을 배치하고, Excalidraw·Kleki·PaintZ에 도형을 그리자 **5개 도구에서 실행 취소가 활성화**됐다. Ray Optics의 빈 작업 안내도 사라졌다. 해당 UI 상태는 현재 확장이 보내는 텍스트에 포함되지 않는다. 실행 취소 활성화로 확인할 수 있는 것은 편집 이력이며 학습 여부는 별도 근거가 필요하다.
- Falstad는 빈 회로에 소자 4개를 연결해도 같은 조건에서 화면에 보이는 비편집 텍스트와 컨트롤 9개의 상태가 같았다. Logo Interpreter는 명령으로 삼각형을 그렸고 기록이 1개 늘었지만 기록 패널은 닫혀 있었다.

## 모델 비교와 베타 지표

같은 41개에서 이전 4,743건 모델은 27개, 10,168건 모델은 29개를 맞혔다. 예전 합성 화면을 재검토해 304건을 추가한 10,472건 후보는 28개를 맞혔다. 10,168건 모델은 전체 41개에서 공부·보류 화면을 딴짓으로 판정한 사례 1개, 실제 딴짓을 놓친 사례 3개가 있었다.

별도로 과거 공개 Chrome 화면 46개 중 학습 메타데이터가 겹친 1개를 제외한 45개에서 4,743건 모델은 41개, 10,168건 모델은 **42개(93.3%)**를 맞혔다. 이 45개 역시 기존에 수집한 화면을 재생한 결과다.

팀원 베타에서 **공부 1시간당 오알림 후보 수**를 계산하려면 팀원이 공부로 표시한 구간의 확인된 오알림 수를 실제 공부 시간으로 나눈다. 지속적인 딴짓 검출률은 알림 조건을 충족한 실제 딴짓 구간 중 후보가 발생한 구간의 비율이다. 후보가 없던 시간도 사람이 활동을 표시해야 누락을 확인할 수 있다. [무알림 베타 사용법](team_pilot/README.md)

## 이전 4,743건 모델의 모의 세션과 실행 비용

이 절의 수치는 이전 가중치로 측정했다. 10,168건 모델의 실제 세션 지표와 응답 시간은 별도 측정이 필요하다.

- 실제 화면을 순서와 시간에 맞춰 재생한 4시간 모의 세션에서는 알림 조건을 충족한 딴짓 구간 7개 중 5개에서 후보가 생겼다. 공부로 정한 3시간 1분 20초 동안 오알림 후보는 0회였다.
- Next.js 문법 1시간 모의 세션은 10/10으로 공부를 맞혔고 오알림 후보는 0회였다. 딴짓 구간은 없었다. 트랜스포머 1시간 모의 세션에서는 분석 가능한 15개 구간을 맞혔고 1개 구간은 개인정보 보호로 생략했다.
