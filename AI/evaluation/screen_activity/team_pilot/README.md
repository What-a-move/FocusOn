# 팀 무알림 베타

10,168건 모델이 알림을 보냈을 시점을 각자의 Mac에 기록합니다. 사용자가 세션을 시작해야 현재 탭이나 창을 관찰합니다. 종료 후 후보 시각과 실제 활동을 표시하면 공부 1시간당 오알림을 볼 수 있습니다.

## 처음 실행

Apple Silicon Mac, macOS 14 이상, Chrome 120 이상, Python 3.11 및 Xcode Command Line Tools가 필요합니다. 저장소 루트에서 다음을 실행하세요. 처음에는 모델 인코더와 Python 라이브러리를 내려받습니다.

```sh
cd AI/evaluation/screen_activity
python3.11 -m venv .venv
source .venv/bin/activate
python -m pip install -r team_pilot/requirements.txt
python setup_encoder.py
sh team_pilot/pilot/native/build.sh
python team_pilot/run.py
```

대시보드가 자동으로 열립니다. 직접 열 때는 `http://127.0.0.1:18743`을 사용하세요. 다음번에는 같은 폴더에서 `.venv/bin/python team_pilot/run.py`만 실행하면 됩니다.

1. 대시보드에서 **연결 설정 → 연결 코드 보기**를 누르세요. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켠 뒤 **압축해제된 확장 프로그램을 로드**에서 저장소의 `AI/evaluation/screen_activity/team_pilot/chrome` 폴더를 고르세요. 확장 팝업에 코드를 입력하고 사이트 접근을 허용하세요. 제외할 도메인도 여기서 지정할 수 있습니다.
2. 대시보드에서 **화면 기록 권한 요청**을 누르세요. macOS에서 권한을 허용한 뒤 재실행을 요구하면 같은 명령으로 다시 시작하세요.
3. 수집에 동의하고 **무알림 테스트 시작**을 누른 뒤 평소처럼 공부하세요. 약 15초 체류 후 Chrome은 활성 탭 메타데이터, 데스크톱은 전면 앱·창 메타데이터를 봅니다. 판정에 필요한 경우 각각 DOM 또는 해당 창의 Apple Vision OCR을 사용합니다. 새 탭과 로컬 대시보드, Discord 등 지정된 민감 앱은 수집에서 제외합니다. 허용된 전면 VS Code는 공부로 처리합니다.

## 후보 검토

**세션 종료** 후 알림 후보마다 실제 활동을 고르세요. 회의·휴식·음악은 따로 표시할 수 있습니다. **실제 활동 시간**에는 후보가 생기지 않은 구간까지 공부·딴짓 등 실제 활동을 표시하세요. 그래야 오래 딴짓했지만 후보가 생기지 않은 구간도 확인할 수 있습니다. 브라우저에서 그림이나 도형을 그리는 캔버스 작업도 실제로 공부했다면 공부로 표시하세요.

- 일반 강도에서 본문으로 확인된 이탈이 연속 60초를 넘거나, 최근 10분 내 30초를 넘는 이탈이 두 번이면 후보가 됩니다. 약 10초마다 확인하고 5분 쿨다운을 적용합니다. 소리나 알림 팝업은 뜨지 않습니다.
- **공부 1시간당 오알림**은 사람이 공부로 표시한 구간에서 실제 공부였다고 확인한 후보 수를 사람이 표시한 공부 시간으로 나눈 값입니다. 공부 30분 동안 잘못 울릴 뻔한 후보가 1회면 2회/h입니다. 관찰하지 못한 시간이 있거나 검토가 남았으면 잠정값입니다. 관찰한 공부 시간이 0이면 산출을 보류합니다.
- **결과 JSON 저장**은 후보 시각·직접 표시한 구간·집계를 내보냅니다. 원본 화면·본문·제목·URL은 포함하지 않습니다. 세션 기록과 확장 연결 키는 본인 Mac의 `~/Library/Application Support/FocusOn Local Pilot`에 보관합니다. 팀원끼리는 검토를 마친 결과 JSON을 공유하면 됩니다.

정책과 관찰 흐름 테스트는 이 디렉터리에서 `python -m unittest discover -s pilot/tests`로 실행합니다.
