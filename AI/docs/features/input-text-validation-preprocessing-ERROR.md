# DOM·OCR 입력 텍스트 검증·전처리 오류 기록

## 오류 001 — HTML 태그 제거 후 줄 끝 공백 잔존

- 관련 Issue: [#11](https://github.com/What-a-move/FocusOn/issues/11)
- 발생일: 2026-09-30
- 심각도: 낮음
- 상태: 해결
- 재현: `python3 -m pytest -q AI/tests/test_text_cleaner.py` 실행 시 본문 정제 테스트 1개 실패.
- 기대 결과: 태그 제거 뒤 `첫째 둘째\n\n끝`.
- 실제 결과: 첫 줄 끝에 공백이 남음.
- 원인: 알려진 HTML 태그를 공백으로 바꾼 뒤 줄 끝 공백을 제거하지 않았다.
- 해결: 본문형 문단에 한해 줄바꿈 주변 공백을 정리했다. 코드·표의 들여쓰기 규칙은 유지했다.
- 검증: 동일 테스트를 포함한 전처리 테스트 37개 통과.
