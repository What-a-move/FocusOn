# Streamlit 키워드 실험 재반영 오류

## 오류 기본 정보

- 오류 001 / 2026-10-22 / Issue #11의 로컬 평가 도구
- 심각도: 보통. 상태: 원인 조사 중, 재시작으로 우회.
- 환경: macOS, Python 3.11, Streamlit, Kiwi 0.23.1.

## 재현 방법과 실제 결과

1. 기존 Streamlit 세션에서 합성 데이터 분석을 실행한다.
2. Python 코드 변경 후 웹의 Rerun으로 재반영한다.
3. 이번 실행에서는 프로세스 종료 코드 139와 브라우저 연결 오류가 관찰됐다. 모든 환경에서 재현되는 것으로 확정하지 않는다.

기대 결과는 최신 코드로 입력 화면을 유지하는 것이다. 종료 시 결과를 새 판정으로 제공하지 않았다. 원문/비밀 값은 이 기록에 포함하지 않는다.

## 원인 및 우회

- 실제 원인: 미확정. 종료 코드만으로 Kiwi, Streamlit 또는 다른 네이티브 라이브러리의 원인으로 단정하지 않는다.
- 우회: 기존 프로세스가 종료된 것을 확인하고 동일 포트에서 새 프로세스를 시작했다. `--server.fileWatcherType none`으로 파일 자동 감시를 끈 실행을 사용한다. 이 실행에서는 후속 코드 변경 시 서버를 재시작해야 한다.
- 관련 로컬 테스트 55 passed와 별도 CLI의 실제 Qwen 36건 평가 성공은 웹 재반영 결함의 원인 해결을 뜻하지 않는다.

## 남은 작업

- 네이티브 종료 진단과 안전한 재반영 방법은 별도 확인이 필요하다. 현재 평가는 깨끗하게 시작한 프로세스를 사용한다.
