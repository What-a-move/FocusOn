# AI 다음 작업

> AI 담당자는 작업 시작 전에 이 문서를 확인하고, 작업 종료 후 다음 작업을 갱신한다.

## 가장 먼저 진행할 작업

- 작업명: 목표 관련성 분석 API MVP 기획·계약 확정
- 담당 영역: AI
- 우선순위: 높음
- 상태: 예정

## 작업 목적

Desktop OCR 결과와 Extension 페이지 텍스트를 학습 목표와 비교하는 첫 AI API를 확정한다. 명확한 요청은 규칙·임베딩으로 처리하고 애매한 요청만 LLM으로 판단할 수 있는 구조를 준비한다.

## 선행 조건

- 루트 `docs/API_CONTRACT.md` 확인
- Desktop·Extension에서 전달할 최소 데이터 확인
- Server의 AI 요청·결과 저장 범위 확인
- 원본 화면·카메라 영상 미저장 원칙 확인
- OCR은 클라이언트에서 실행하고 AI는 텍스트 정제·품질 판단을 담당한다는 역할 확인
- 관련 기능의 PLAN·ERROR·REPORT 파일 준비

## 예상 작업 순서

1. Server·Frontend(`apps`) 담당자와 `api_spec.md`의 요청·응답을 확인한다.
2. FastAPI, Pydantic, pytest 기반 실행 환경을 기능 기획서에서 확정한다.
3. OCR·페이지 텍스트 정제와 품질 판정 기준을 정의한다.
4. 규칙 기반 관련성 판단을 구현하고 임베딩·LLM Client Interface를 분리한다.
5. 임베딩 유사도 구간과 LLM Fallback 조건을 평가 데이터로 확정한다.
6. 정상·경계·민감 정보·Prompt Injection 평가 케이스를 작성한다.
7. Server 연동 전 API·분석·회귀 테스트를 통과시킨다.
