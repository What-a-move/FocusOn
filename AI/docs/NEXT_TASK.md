# AI 다음 작업

> AI 담당자는 작업 시작 전에 이 문서를 확인하고, 작업 종료 후 다음 작업을 갱신한다.

## 가장 먼저 진행할 작업

- 작업명: AI 입력·출력 계약과 실행 방식 확정
- 담당 영역: AI
- 우선순위: 높음
- 상태: 예정

## 작업 목적

Desktop·Extension·Server가 AI 분석을 같은 형식으로 요청하고 결과를 해석할 수 있는 기준을 만든다.

## 선행 조건

- 루트 `docs/API_CONTRACT.md` 확인
- Desktop·Extension에서 전달할 최소 데이터 확인
- Server의 AI 요청·결과 저장 범위 확인
- 원본 화면·카메라 영상 미저장 원칙 확인

## 예상 작업 순서

1. 입력 필드와 출력 상태값을 정의한다.
2. 관련성 점수·신뢰도·`UNCERTAIN` 기준을 정한다.
3. Python 실행 방식과 의존성을 확정한다.
4. 정상·경계·민감 데이터 제외 평가 케이스를 만든다.
5. AI API 초안과 테스트 방법을 문서화한다.

## 이후 작업 후보

- 화면·페이지 관련성 분석기 구현
- 목표 이탈 판단 기준 구현
- 분석 결과 Server 연동
- 평가 자동화와 기준 점수 정리
- 모델·프롬프트 버전 관리
