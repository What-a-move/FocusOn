# AI 데이터 수명과 개인정보 경계

## 문서 상태

- 상태: 팀 검토용 초안
- 버전: `0.2.0-draft`
- 기준일: 2026-09-22
- 상위 기준: 루트 `docs/DATA_PRIVACY.md`
- 관련 규칙: `AI-PRIV-001`, `AI-PRIV-002`, `AI-PRIV-003`, `AI-CACHE-001`, `AI-VISION-003`
- 관련 문서: [콘텐츠 수집 계약](content_acquisition_spec.md), [목표·세션 모델](goal_session_spec.md), [피드백 명세](feedback_personalization_spec.md), [노트 명세](session_note_spec.md)

이 문서는 FocusOn AI 흐름에서 데이터가 생성되고 전달되고 삭제되는 경계를 정의한다. 법률 검토를 거친 개인정보 처리방침을 대신하지 않는다. 보존 기간이 합의되지 않은 데이터는 임의의 영구 저장이나 고정 TTL을 적용하지 않는다.

## 1. 기본 원칙

- 제외 여부와 민감 화면 여부를 콘텐츠 추출·캡처보다 먼저 확인한다.
- 원본 화면과 카메라 영상은 사용자 기기 메모리 밖으로 보내거나 저장하지 않는다.
- 전체 DOM과 OCR 원문을 Server·AI 로그, DB, 캐시, Trace, Agent 체크포인트에 남기지 않는다.
- 분석에 필요한 최소 문단만 로컬에서 정제하고, Server가 사용자·목표·회차 소유권을 검증한 뒤 AI에 전달한다.
- AI가 명백한 비밀 값이나 민감정보를 발견하면 모델 호출을 중단하고 원문 없는 오류 코드만 반환한다.
- 삭제는 DB뿐 아니라 캐시, 벡터, 체크포인트, 비동기 작업과 파생 노트까지 전파한다.
- 사용자 식별자를 가명처리한 로그를 `완전 익명`이라고 표현하지 않는다.

## 3. 제외·민감 화면 처리

```text
활성 탭·앱 확인
  → 사용자 제외 설정 확인
  → 로그인·결제·인증·메신저 등 민감 화면 확인
  → 권한·세션 상태 확인
  ├─ 통과: 허용된 최소 콘텐츠 추출
  └─ 실패: 캡처·OCR·ColPali·Server 전송·AI 호출 중지
```

DOM이 비어 있다는 이유만으로 캡처를 허용하지 않는다. OCR과 ColPali 경로도 같은 제외·권한 검사를 다시 통과해야 한다.

## 4. 단계별 개인정보 검사

### 4.1 Extension·네이티브 모듈

- 폼, 입력값, `contenteditable`, 비밀번호, 인증 영역을 처음부터 추출하지 않는다.
- URL은 호스트 등 필요한 최소 메타데이터만 사용하고 경로·쿼리·Fragment를 기본 제외한다.
- 이메일, 전화번호, 주소, 인증 토큰, API Key 후보를 제거하거나 마스킹한다.
- 안전하게 분리할 수 없으면 전송하지 않는다.

### 4.2 Server

- 인증된 사용자와 `goalId`, `sessionId`, `runId` 소유권을 확인한다.
- 저장된 최신 `goalVersion`과 요청 버전을 비교한다.
- 제외 정책과 기록 동의 범위를 다시 확인한다.
- `recordOnly=true`이면 콘텐츠 근거·노트·알림을 생성하지 않고 허용된 최소 집계만 유지한다.
- AI에 전달할 문단 수, 문단 길이, 전체 요청 크기를 제한한다.

### 4.3 AI

- Schema와 허용된 출처를 검증한다.
- Bearer Token, JWT 형태, 알려진 API Key Prefix, 결제 카드 후보 등 명백한 비밀 값을 2차 검사한다.
- 민감 문자열을 오류 메시지, Trace, 캐시 키에 복사하지 않는다.
- 모델 입력에는 분석에 필요 없는 식별자와 원본 URL을 포함하지 않는다.

## 5. 외부 모델 전송

클라우드 LLM·임베딩 또는 서버 ColPali를 사용하면 정제 텍스트나 이미지가 외부 시스템으로 전달될 수 있다. 다음 항목이 확정되기 전에는 해당 경로를 기본 활성화하지 않는다.

- 제공자와 처리 지역
- 입력·출력 보존 기간
- 모델 학습 이용 여부와 비활성화 옵션
- 전송 암호화와 접근 통제
- 사용자 고지와 동의 범위
- 삭제 요청의 제공자 측 전파 가능 여부
- 장애 시 로컬·규칙 기반 Fallback

화면 이미지 비전송과 정제 텍스트 외부 전송은 서로 다른 조건이다. 하나를 허용했다고 다른 하나가 자동으로 허용되지 않는다.

## 6. ColPali 개인정보 경계

ColPali는 OCR 대체가 아니라 PDF·Canvas·이미지·슬라이드처럼 시각 구조가 중요한 콘텐츠의 검색·근거 보강 후보로 사용한다.

### 로컬 실행

- `AI-PRIV-002`를 유지할 수 있다.
- 모델 크기, GPU·메모리, 배터리, 초기 다운로드와 응답 시간을 검증해야 한다.
- 이미지와 중간 Tensor를 파일·로그에 저장하지 않는다.

### Server 또는 외부 실행

- 원본 이미지 전송 때문에 현재 확정 개인정보 원칙과 충돌한다.
- `DECISION_RECORD.md`, 루트 `DATA_PRIVACY.md`, 사용자 동의 UI와 삭제 정책을 먼저 변경해야 한다.
- 변경 승인 전에는 실험 경로로도 실제 사용자 화면을 전송하지 않는다.

### 임베딩 저장

시각 임베딩은 원본 복원이 절대 불가능하다고 가정하지 않는다. 사용자·목표 범위를 분리하고 원본 삭제, 모델 교체, 개인화 초기화 시 함께 삭제한다.

## 7. 캐시와 삭제 전파

캐시 키에는 원문을 넣지 않고 다음 버전을 구분한다.

```text
user scope
+ goalId / goalVersion
+ sanitized content hash
+ preprocessing version
+ extractor version
+ embedding / model version
+ prompt version
+ policy version
+ feedback version
```

다음 이벤트는 관련 캐시와 파생 결과를 무효화한다.

- 목표 수정 또는 삭제
- 관련성 피드백 수정·삭제
- 제외 설정 변경
- 전처리·추출기·모델·Prompt·정책 버전 변경
- 기록 삭제 또는 개인화 초기화
- 보존 기간 만료

목표·콘텐츠 관련성 캐시를 시간에 따라 변하는 최종 이탈·알림 결과로 재사용하지 않는다.

## 8. 로그 허용 목록

기본 로그에는 다음 항목만 허용한다.

- 요청 ID와 이벤트 ID
- 기능명과 처리 단계
- 상태값과 원문 없는 오류 코드
- 모델·Prompt·추출기·정책 버전
- 단계별 처리 시간과 재시도 횟수
- 필요 시 가명화한 사용자·세션 참조

전체 URL, 제목·본문 원문, OCR 원문, 이미지, 개인 메시지, Authorization Header, API Key, 모델 원본 출력은 기록하지 않는다.

최근 7일은 분석 창일 뿐 원천 학습 기록의 보존 기간이 아니다. 개인화 집계와 `PersonalBreakProfile`은 기능 ON 및 유효한 기록 저장 동의가 있을 때만 생성하며, 카메라 원본·프레임·랜드마크·정확한 시선 좌표를 포함하지 않는다.

## 9. 보존 기간 결정 전 규칙

기획서의 `24시간 캐시` 같은 기존 값은 팀 검토 전 제안이다. 각 데이터의 TTL을 결정할 때 다음을 함께 기록한다.

- 보존 목적과 최소 필요 기간
- 삭제 작업의 실행 주기와 실패 재시도
- DB·Cache·Vector Store·Checkpoint·Queue 전체 전파 범위
- 계정 삭제와 개별 기록 삭제의 완료 조건
- 백업과 진단 로그의 예외 범위
- 담당 서비스와 검증 테스트
