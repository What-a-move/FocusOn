# AI 작업 컨텍스트

> AI 담당자가 작업 시작 시 가장 먼저 읽는 문서다.
> 작업이 끝나면 현재 상태와 다음 담당자가 알아야 할 내용을 갱신한다.

## 담당 영역

- 학습 목표와 화면·페이지 정보의 관련성 판단
- 목표 이탈 및 집중 상태 보조 판단
- 분석 결과의 상태값·점수·신뢰도 반환
- AI API 입력·출력 계약 관리
- 평가 데이터와 모델·프롬프트 품질 확인

## 현재 상태

### 완료된 작업

- AI 기본 디렉터리와 평가 디렉터리가 생성되어 있다.
- AI 전용 문서 구조와 기능별 템플릿을 구성했다.
- 공통 API 응답 초안은 루트 `docs/API_CONTRACT.md`에 정의되어 있다.

### 진행 중인 작업

- AI 실행 방식과 Python 의존성 확정
- 입력·출력 스키마 및 관련성 판단 기준 확정
- 평가 데이터와 기준 결과 구성

### 아직 진행하지 않은 작업

- 실행 가능한 AI 서버 진입점 구현
- 모델 또는 분석 API 연결
- Server 연동
- 성능·정확도 평가 자동화

## 현재 기술

- 언어: Python 예정
- 실행 방식: 검토 필요
- 분석 대상: 화면·페이지에서 추출한 텍스트와 메타데이터
- 카메라 분석: MediaPipe 기반 클라이언트 처리 결과를 필요할 때 상태값으로 연동
- 원본 저장: 원본 화면·카메라 영상은 기본 저장하지 않음

## 예상 데이터 흐름

```text
Desktop / Extension
  → 최소 분석 데이터
  → AI 분석 API
  → 관련성·집중 상태·신뢰도
  → Server 저장 또는 Client 표시
```

## 반드시 지켜야 하는 조건

- 입력 데이터에 비밀번호·결제 정보·개인 메시지가 포함되지 않도록 확인한다.
- 원본 화면·카메라 영상을 기본 저장하지 않는다.
- 판단이 어려운 경우 확정적인 `FOCUSED` 또는 `DISTRACTED` 대신 `UNCERTAIN`을 반환한다.
- 모델·프롬프트·임계값 변경은 `DECISION_RECORD.md`에 기록한다.
- 분석 결과에는 최소한 상태값과 신뢰도 기준을 포함한다.
- 기능 추가 전 `features/` 안에 기획서를 먼저 작성한다.

## 작업 종료 시 갱신

- 완료·진행 중·미착수 작업
- 입력·출력 계약 변경
- 모델·프롬프트·임계값 결정
- 발생한 오류와 평가 결과
- 다음 작업과 선행 조건
