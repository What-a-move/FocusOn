# FocusOn AI

FocusOn의 화면·페이지 관련성 판단과 분석 결과 반환을 담당하는 AI 영역이다.

## 현재 상태

- Python 기반 디렉터리 구조만 구성되어 있다.
- AI 실행 명령과 의존성은 담당자 협의 후 확정한다.
- 원본 화면과 원본 카메라 영상은 기본 입력·저장 대상으로 사용하지 않는다.
