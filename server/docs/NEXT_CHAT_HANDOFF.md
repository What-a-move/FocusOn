- 별도 작업으로 서버 생성 `requestId`를 유지하고 `X-Trace-Id`를 분리한다. 허용 형식 `^[A-Za-z0-9-]{8,64}$`; 누락·불일치 시 서버 생성, MDC와 응답 헤더에 반영한다. traceId는 인증·인가·멱등성·DB 키에 사용하지 않는다.

- 요청 본문·토큰·쿠키·인증 헤더·전체 URL·query·이름·이메일·제목·DOM/OCR·AI 프롬프트와 응답 원문을 로그에 남기지 않는다.
- `docs/INTEGRATION_DEBUG.md`의 추적 방법을 따르되 일부 구현 상태 표기는 오래됐을 수 있다. Desktop·Extension에는 로거가 병합됐고, 서버 trace 연동은 이 문서 작성 시 미구현이다.
