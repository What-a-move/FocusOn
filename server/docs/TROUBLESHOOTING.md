# 백엔드·연동 트러블슈팅

이 문서는 사실 확인과 재현 범위를 구분한 개인 학습용 기록이다. 수치는 실행 결과 또는 확정 정책으로 확인된 것만 적는다. 비밀값과 실제 사용자 화면 내용은 기록하지 않는다.

## 1. 미구현 API가 로그인 해제로 이어짐 — Issue #112

- **증상:** Desktop에서 미구현 API를 호출할 때 `401 AUTH_RELOGIN_REQUIRED`가 오면 클라이언트가 로그인 정보를 지운다는 QA 보고.
- **재현:** 실제 내장 HTTP 서버 테스트에서 인증 서비스의 성공을 대역으로 설정한 미구현 API 요청은 수정 전 기대한 404가 아니었다. 무인증 및 외부 `/error` 접근도 확인했다.
- **원인 및 수정:** Spring Security의 `anyRequest().denyAll()`이 내부 ERROR 디스패치에 적용되는 경로를 확인하고, 해당 디스패치만 허용하도록 수정했다. 외부에서 `/error`에 직접 요청하는 일반 REQUEST는 기존대로 차단한다.
- **결과:** 수정 후 테스트 대역 기준 미구현 경로 **404**, 직접 `/error`와 미인증·위조 토큰 **401**, 만료 토큰은 기존 만료 코드 유지. `./gradlew build` 통과.
- **추가 검증:** 재리뷰에서 405의 공통 오류 본문 누락을 재현하고 수정했다. 404·405 외 오류 디스패치는 기존 동작을 유지하므로 공통 형식 보장은 별도 검토가 필요하다.
- **한계:** 실제 인증 서비스는 대역이므로 실 JWT·PostgreSQL·Desktop 통합은 미검증. 현재 PR·병합 상태는 GitHub에서 재확인한다. 테스트 수치: 해당 내장 서버 테스트 **4개**.

## 2. Desktop과 Extension 연결 표시 불일치

- **증상:** 코드 입력 후 Desktop은 연결 완료, Extension은 `연결 전`으로 표시된 테스트가 있었다.
- **확인:** 서버의 사용된 연결 코드와 활성 Extension 기기·토큰 family가 존재했다. Desktop은 서버 연결을, Extension은 Chrome 로컬 저장소의 Refresh Token 유무를 기준으로 한다.
- **미확정:** 서로 다른 Extension 설치본·Chrome 프로필, 토큰 저장/조회 실패, 응답 유실, 당시 임시 빌드 문제 중 실제 원인은 확인하지 못했다.
- **다음 검증:** 같은 Chrome 설치본에서 응답 상태·토큰 저장 성공 여부·팝업 재실행 후 인증·새 코드 재연결 및 이전 토큰 폐기를 확인한다. 코드·토큰 원문은 기록하지 않는다.

## 3. macOS 화면 기록 권한이 켜져도 인식되지 않음

- **증상:** 시스템 설정에서 `Electron` 토글을 켜고 앱을 재시작한 뒤에도 Desktop은 화면 기록이 꺼졌다고 표시했다.
- **확인:** Desktop은 Electron 권한 상태 API 결과를 사용한다. 개발 실행 시 Swift 화면 관측 도우미 빌드도 중복 `SwiftBridging` 모듈 정의 때문에 실패해 도우미 없이 실행했다.
- **미확정:** 화면 권한 실패가 Swift 빌드 문제 때문이라는 증거는 없다. 설정의 Electron이 실제 실행 주체와 같은지, 권한 조회·앱 서명·패키징의 영향은 별도 확인이 필요하다. 배포용 FocusOn도 반드시 검증한다.

## 4. Chrome Extension 빌드 로드 실패

- **증상:** Chrome이 `__next...`처럼 예약된 접두어가 있는 최상위 파일 때문에 빌드 폴더를 로드하지 못했다.
- **임시 조치:** 테스트용 복사본을 변환해 로드했지만 원본과 동일한 모든 동작을 보장하지는 않았다.
- **팀원 보고:** PR #108이 예약 이름 처리와 실제 서버 연결 성공을 보고했다. 당시 열린 PR이었으므로 현재 병합 및 QA 상태는 GitHub에서 재확인한다.

## 5. 로컬 Swift 도우미 빌드 실패

- **증상:** Swift `module.modulemap`과 `bridging.modulemap`이 `SwiftBridging`을 중복 정의해 개발 빌드가 실패했다.
- **확인:** 시스템 파일을 수정하지 않는 임시 VFS 환경에서는 전체 빌드가 성공한 이전 기록이 있다. 일반 환경이 복구됐다는 뜻은 아니다.
- **상세:** `features/auth-lifecycle-ERROR.md`, `features/auth-lifecycle-QA.md`. 시스템 도구 복구 전 실제 설치 환경을 확인한다.
