# Backend 다음 작업

## 작업명

공통 기반과 최초 PostgreSQL 스키마 구현

- 우선순위: 높음
- 상태: 준비됨

## 목적

확정된 FocusOn API 명세를 기준으로 도메인 API를 안전하게 추가할 수 있는 서버 기반을 만든다.

## 순서

1. 기능 기획서에 공통 응답·예외 처리 범위를 기록한다.
2. 공통 성공 응답, 오류 응답, requestId, validation 예외 처리를 구현한다.
3. Notion ERD와 API 필드를 대조해 V1 migration을 작성한다.
4. 사용자, 기기, 목표, 세션 핵심 Entity와 Repository를 구현한다.
5. Google 로그인 교환과 token 정책을 구현한다.
6. 목표와 세션 MVP API를 구현한다.
7. 분석·리포트 API를 연결한다.
8. P1인 세션 목록과 주간 리포트는 MVP 안정화 뒤 구현한다.

## 완료 조건

- [ ] 관련 `*-PLAN.md`가 있다.
- [ ] 구현 경로·필드·권한이 Notion 명세와 일치한다.
- [ ] migration이 빈 DB와 기존 개발 DB에 적용된다.
- [ ] 정상·검증·인증·충돌 응답을 확인했다.
- [ ] 토큰과 민감 데이터가 로그에 없다.
- [ ] `*-REPORT.md`에 결과와 남은 위험을 기록했다.
