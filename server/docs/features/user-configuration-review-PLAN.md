# 사용자 설정 리뷰 수정 계획

- Issue: #83 / 기준: PR #82 CodeRabbit 리뷰
- 범위: 닉네임 중복 경쟁, 동의·집중 설정 최초 저장 경쟁, 반복 테스트 안정성, 동의 출처 계약 확인.
- 기존 Flyway V3와 사용자 미커밋 변경은 수정하지 않는다.
- 닉네임 유일 제약 충돌만 공통 409로 변환하고 다른 무결성 오류는 그대로 전달한다.
- 동일 사용자의 동의·집중 설정 저장 전 사용자 행을 잠근다.
- 사용자 결정에 따라 최신 동의·철회 요청의 출처를 저장한다. 기존 기록의 알 수 없는 출처는 NULL로 유지한다.
- 단위·API 테스트, PostgreSQL 동시성 검증, 빌드·Checkstyle과 문서를 확인한다.
