# 미구현 API 404 응답

- Issue: #112
- 범위: 인증된 미구현 API 요청과 Servlet 오류 전달의 보안 경계.
- 유효 인증 요청은 미구현 경로에 404를 반환하고 재로그인 오류를 내지 않는다.
- 무인증·위조·만료 토큰의 기존 인증 정책과 외부 `/error` 접근 제한을 유지한다.
- 실제 내장 서버를 사용하는 테스트에서 오류 전달을 재현하고 회귀를 검증한다.
- 404 응답에 요청 원문이나 인증 정보를 노출하지 않는다. DB·API 기능 추가는 없다.
- 미구현 경로의 404 본문은 사용자 요청의 `NOT_FOUND`와 공통 오류 필드로 반환한다.
  Notion 정본 접근이 되지 않아 해당 코드의 정본 동기화는 별도 확인이 필요하다.
