# Extension 연결 해제 코드 리뷰

2026-10-28 독립 리뷰: 다른 Extension 토큰으로 같은 사용자 소유의 다른 Extension을 해제할 수 있는 권한 결함을 발견해 자기 기기만 허용하도록 수정했다. 해당 회귀 테스트를 추가했다. 수정 후 잠금 순서, 소유권, token family 폐기에서 추가 확정 문제는 발견하지 못했다. 리뷰어는 테스트를 별도 실행하지 않았다.

기기 목록 추가분 독립 리뷰: 본인 ACTIVE 기기만 Desktop에 제공하고 token·설치 ID를 노출하지 않는다. 연결 해제 시 재검증을 확인했으며 확정 P1/P2는 없었다. 리뷰어는 테스트를 직접 실행하지 않았다.
