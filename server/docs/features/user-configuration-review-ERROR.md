# 사용자 설정 리뷰 오류 기록

- Issue: #83
- 닉네임 중복 사전 검사와 DB 저장 사이에 경쟁이 가능하다. DB 유일 제약 위반만 409로 변환하도록 저장 시 flush한다. 실제 동시 요청의 PostgreSQL 검증은 별도 확인이 필요하다.
- 동의·집중 설정 최초 저장은 조회 후 삽입 경쟁이 가능하다. 사용자 행 잠금으로 같은 사용자 저장을 직렬화한다. PostgreSQL 동시성 검증은 별도 확인이 필요하다.
- 기존 테스트가 고정 닉네임을 사용해 같은 영속 DB의 재실행에서 중복될 수 있어 매 실행마다 새 값을 생성한다.
- Notion API 요청과 Desktop은 `consentSource`를 사용하지만 서버가 저장하지 않았다. 사용자 결정에 따라 동의 상태와 함께 최신 출처를 저장한다. 이전 기록은 출처를 알 수 없어 NULL이다.
- 최초 Checkstyle 실행에서 줄 길이 위반이 발생해 줄바꿈을 수정했다.
