# 일간·달력 리포트 자체 점검

2026-11-10. 이 문서는 구현자의 자체 점검이며, `rules/code-review-isolation.md`의 별도 컨텍스트 리뷰를 충족하지 않는다. 현재 대화의 sub-agent 사용 금지 조건에 따라 별도 리뷰 에이전트를 실행하지 않았다. PR 준비 완료로 표시하지 않는다.

- 조회 query가 사용자 ID·고정 studyDate·ENDED/ABANDONED를 직접 제한한다. goals와 join하지 않아 현재 목표 수정/삭제와 무관하다.
- 컨트롤러는 필수 X-Device-Id를 공통 validator로 검사하며 Security의 Bearer/활성 family/소유권 검증을 재사용한다. Service에서 Desktop 전용을 검사한다.
- 월 합계는 일별 SUM/COUNT 단일 query, 일간 합계는 동일 목록에서 계산한다. 별도 조회 간 종료 경합으로 합계와 목록이 달라지지 않는다.
- 엄격 날짜 검증, 윤년, 활동일 경계, 여러 세션 합산, 동일 시작 시각 ID 내림차순, 사용자 격리와 빈 결과를 테스트했다.
- 원문·AI 호출·로그 추가 없음. 기존 summary/학습 정리/세션 명령을 재구현하지 않았다.
- V21은 새 인덱스만 생성한다. 격리 PostgreSQL의 별도 schema에서 V20 기록을 만든 뒤 V21 적용 전후 전체 세션 JSON 동일성을 확인했다.
- 아직 없는 계약을 필드로 추가하지 않았다. 새 권한·날짜 배열·정렬 결정은 사용자가 명시적으로 승인했고 정본 접근 한계를 기록했다.
