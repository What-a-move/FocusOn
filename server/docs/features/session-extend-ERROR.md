# 세션 시간 연장 오류 기록

- Checkstyle에서 테스트 코드의 100자 초과 한 줄이 발견되어 줄을 나누고 전체 빌드를 재실행해 통과했다.
- Notion 원본 조회는 접근할 수 없었다. 제공된 세션 정책과 저장소의 Desktop API 인계 문서를 사용했으며 원본 대조는 미완료다.
- 독립 브랜치 #167과 #168에 각각 Flyway V11이 있어 충돌했다. 최신 dev의 V15 뒤로 연장 이력 migration을 V16으로 변경했다. 이전 V11 연장 migration이 이미 적용된 DB는 별도 이력 확인이 필요하다.
- IntelliJ에서 미리 충돌을 해결한 파일에서 연장 메서드와 테스트가 누락됐고, 빌드 오류를 통해 확인해 Heartbeat 코드와 함께 복원했다.
