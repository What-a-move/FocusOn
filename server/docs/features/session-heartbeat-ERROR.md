# 세션 Heartbeat 오류 기록

## PostgreSQL 잠금 대기 계측

- 관련 Issue: #167. 상태: 테스트 계측 수정 후 통과.
- 두 동시 요청이 사용자 행 잠금을 기다리는지 확인할 때 직접 `pg_blocking_pids`만 세면 두 번째 대기자가 첫 대기자를 통해 간접적으로 기다리는 상황을 놓쳤다.
- 재귀 대기 체인을 조회하고 실제 대기자가 2개 이상임을 확인하도록 수정했다. 격리 PostgreSQL에서 해당 테스트가 통과했다.

## 실제 Google 인증 QA 미완료

- PKCE 인증 창을 통한 실계정 검증은 90초 동안 인증이 완료되지 않아 시간 초과됐다. 기존 계정·기기나 DB는 삭제하지 않았다.
- 합성 JWT로 검증한 HTTP 200은 Google OAuth 성공을 뜻하지 않는다. 실계정 Swagger 테스트가 남았다.
