# 목표 수정·삭제 오류 기록

- Issue: #97
- 상태: 발생한 오류와 해결·미해결 사항을 기록한다.
- 인증값과 개인정보는 기록하지 않는다.
- 코드 구현 후 최초 Checkstyle에서 import 순서와 테스트 코드 줄 길이 오류가 발생했다. 수정 후 Main/Test Checkstyle이 통과했다.
- Notion 연결 도구에서 정본 API 데이터베이스 조회가 `NOT_FOUND`로 반환됐다. 이슈 및 기존 로컬 계약을 기준으로 구현했으며 정본 상세 대조는 미완료다.
- 2026-11-01: 기존 8080 서버에는 PATCH·DELETE가 보이지 않았다. 기존 서버를 종료하거나 DB를 변경하지 않고 18080의 별도 서버와 격리 DB로 현재 브랜치를 확인했다.
- 2026-11-02 잠금 대기 테스트의 최초 계측은 직접 차단된 요청만 세어 2개 중 1개로 실패했다. PostgreSQL의 대기 사슬을 재귀 조회하도록 보완한 뒤 수정·삭제 각각 실제 대기와 해제 후 정합성을 확인했다. 이후 Checkstyle 줄 길이 오류 2곳을 정리하고 전체 빌드를 통과했다.
