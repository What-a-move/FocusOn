# #342 독립 코드 리뷰

별도 컨텍스트에서 최신 dev 기준 백엔드 diff를 검토했다. 최신 관측 및 전경 검증, 시간 창, 기존 JSON, 기존 알림 권한·receipt·중복 방지 경로를 확인했다.

## 1. Medium — 15초 미만 이탈이 비율 경로에 포함됨

**문제** 기존 조건보다 먼저 발동하는 비율 조건은 과거 이력으로 비율을 충족한 상태에서 새 무관 판정이 들어오면 바로 알림을 만들 수 있었다. 공통 API 계약은 15초 미만 전환을 제외한다.

**해결** 비율 경로에서 현재·과거 이탈이 15초 이상인지 먼저 확인한 뒤 창 안의 구간만 합산한다. 기존 출처별 수집 대기를 그대로 사용하자는 대안도 검토했으나, API를 직접 호출하거나 다른 클라이언트가 연결되어도 같은 서버 기준을 유지하도록 했다. 14초와 15초 경계를 자동 검증에 추가했다.

## Docker Compose 설정 전달 후속

설정 이름, 배포 기본값, 공개 계약과 개인정보 처리에 대한 영향을 독립 검토했다. 변수를 하나만 설정하면 기존 Spring 검증으로 서버 시작이 실패한다는 지적을 반영해 환경 예시의 허용 범위와 시작 조건을 명시했다.
