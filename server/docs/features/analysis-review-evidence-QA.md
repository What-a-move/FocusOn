# 화면 분석의 학습 정리 근거 수신 QA

2026-11-27, JDK 25 및 Spring Boot 4.1.1로 검증했다. AI는 루프백 합성 서버를 사용했고 분석 HTTP 서버는 테스트에서 임시 포트로 실행했다.

| 검증 | 결과 |
| --- | --- |
| 백엔드 `build`, Checkstyle Main·Test, H2 전체 테스트 | 성공. 455건 통과, 환경 조건으로 18건 생략 |
| PostgreSQL 17, Flyway V1~V32, Hibernate 스키마 검증 | 분석·개입·세션 종료·학습 정리 마이그레이션 관련 227건 통과, 생략 0건 |
| 본문이 있는 DOM·OCR, 구버전 응답, 빈 배열과 잘못된 근거 | 정상 근거 1건 수신, 누락·형식·타입·길이·안전 조건 위반은 판정을 유지한 채 근거 폐기 |
| 출처 및 최종 판정 | 메타데이터, 빈 본문, 낮은 신뢰도, 매칭 상태 변경, 미등록 목표 ID, 목표 버전 변경, 종료·재개, 보호 상태에서 근거 제거 |
| 공개 API 및 안전 로그 | 분석 POST·GET에서 라벨·응답 전문 비노출, 합성 AI 호출과 서버 로그는 동일 traceId로 확인 |

첫 Checkstyle 실행에서 테스트 이름과 유니코드 공백 표기의 경고 2건을 수정했다. 재실행은 통과했다.

PostgreSQL 임시 컨테이너는 자동 할당된 루프백 포트를 사용했으며 테스트 뒤 종료했다. 개발 DB 5432와 기존 8080은 건드리지 않았다. 실제 AI 배포, Desktop·Extension 실연동 및 실제 사용자 근거 저장·모델 전송은 검증 범위 밖이다.
