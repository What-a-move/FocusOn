# #342 최근 10분 이탈 비율 알림 검증

## 완료 범위

- 설정한 환경에서 v2 비율 조건만으로 heartbeat가 OFF_TASK 한 건을 만들고, 기존 개입 API가 반환하는 것을 확인했다. 반복 평가에도 한 건을 유지했다.
- 10분 창에서 두 판정의 경계를 자르고, 14초 이탈 제외와 15초 포함, 최소 관측 시간, 대기·보호·판단 보류, cooldown, 기존 JSON, v1 호환을 확인했다.
- 배포 기준 확정 전 비율 조건과 관련 시간 수집은 기본 비활성이다. 실제 환경의 AI 판정과 Desktop 알림 표시는 이번 검증 범위 밖이다.

## Docker Compose 설정 전달 후속

- 기존 Compose는 환경 파일의 비율 설정을 Backend에 넘기지 않았다. 수정 후 합성 환경 파일의 50%·60초가 전달되고 기본·미설정·빈 값은 0·0으로 남는 것을 `docker compose config`로 확인했다. 한 값만 지정하면 기존 Spring 검증에 전달된다.
- Gradle 전체 build와 Checkstyle 통과. 격리 H2에서 518건 통과, 18건 생략, 실패 0건.
