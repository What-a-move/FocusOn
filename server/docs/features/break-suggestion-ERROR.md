# 개발 오류 보고서 — 휴식 제안 생성 (#301)

## 1. 지금 이탈이 짧아도 지난 이탈만으로 휴식 제안이 생김

- 발견: 머지 전 결함 점검(2026-11-23).
- 증상: 0·2·4분에 반복 기준을 넘긴 이탈 3회가 끝난 뒤, 6분 40초에 새 무관 판정이 들어오면 그 이탈이 1초만 지나도 휴식 제안 근거가 나왔다.
- 원인: `breakEvidence`가 사슬의 마지막 이탈이 지금 이탈인지 확인하지 않았다. 지금 이탈은 반복 기준을 넘기지 않으면 사슬에 들지 않아, 최근 10분 안에 남은 지난 이탈 사슬만으로 조건을 채웠다.
- 조치: 지금 열린 이탈이 강도별 반복 기준을 넘긴 경우에만 근거를 계산한다. 사슬은 항상 지금 이탈에서 끝난다.
- 검증: `OffTaskTimelineTests.breakEvidenceWaitsUntilCurrentEpisodeQualifies`(1초·30초 시점 없음, 31초 시점 4회).
