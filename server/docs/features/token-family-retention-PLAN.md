# 토큰 패밀리 보관 기간 정리

- 작업은 #309에서 추적한다. 선행 작업은 #59 인증 수명주기다. 보관 기간은 [공통 데이터 정책](../../../docs/DATA_PRIVACY.md)의 폐기·만료 후 30일을 따른다.
- 기본 5분마다 최대 100건을 확인한다. 마지막으로 확인한 ID 이후에서 이어 가고, 끝에 도달하면 처음부터 다시 확인한다. 폐기와 만료가 모두 일어났다면 먼저 무효화된 시각을 기준으로 한다.
- 사용자와 패밀리를 기존 인증 작업과 같은 순서로 잠근 뒤 보관 기한을 다시 평가한다. 같은 트랜잭션에서 패밀리의 Refresh Token 회전 이력을 먼저 지우고 패밀리를 정리한다.
- 유효한 패밀리와 보관 기간 안의 재사용 감지 이력은 보존한다. 한 건의 저장소 오류는 해당 트랜잭션을 롤백하고 다른 후보에서 계속한다.
- 검증은 격리 PostgreSQL에서 오래된 회전 체인, 만료·폐기 경계, 유효한 패밀리 보존 및 반복 실행을 확인한다.
