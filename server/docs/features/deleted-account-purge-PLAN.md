## 데이터 설계

- 마이그레이션 없음.
- 지우는 것: 세션과 딸린 기록(개입 전송·개입·정책 상태·학습 정리 근거·학습 정리·분석 실행·로컬 이벤트·연장·관측 단위), 목표, 목표 다듬기 대화, 멱등 기록, 분석 제외 도메인, 집중 설정.

- 범위 밖: 기기·token family·Refresh Token·연결 코드는 별도 보관 기준(폐기·만료 후 30일)을 따르는 작업으로 다룬다.

## 처리 흐름

1. 1시간마다 삭제 후 유예(기본 24시간, 설정 `focuson.account-purge.grace`, 최대 7일)가 지났고 지울 기록이 남은 계정을 최대 20개씩 고른다.
2. 계정마다 한 transaction에서 사용자 행을 잠그고 삭제 상태를 다시 확인한 뒤, 자식 → 부모 순서로 지운다.
3. 실패한 계정은 고정 오류 분류만 로그에 남기고 다음 실행에서 다시 시도한다.

유예를 두는 이유: 진행 중이던 세션은 heartbeat가 끊긴 뒤 180초 뒤 ABANDONED가 되고, 학습 정리 작업도 종료 후 몇 분 안에 끝난다. 이 작업들과 겹치지 않게 하루 뒤 지운다(30일 기준 안).
