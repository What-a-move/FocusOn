# 세션 할 일과 목표 프로필 연동 결과

## 기본 정보

- 기능 ID는 DR-024·DR-030, #298·#319다.
- 관련 작업은 [기획서](session-goal-profile-PLAN.md)에 기록했다.

## 구현 결과

- 확정 목표의 기본 문장과 사용자 수정 프로필을 저장한다. 초안이 없으면 내부 Goal AI를 호출한다.
- 목표 1~3개로 세션을 시작하고 실행 기기에서 할 일을 추가할 수 있다. 같은 추가 요청의 재시도는 기존 목록을 반환한다.
- 분석 요청은 목표 버전과 순서가 보존된 사본을 사용한다. 검증한 매칭 ID·목표 버전만 결과 이력에 남긴다.
- v2에서 유효한 본문 RELATED/FAR가 누적 10분에 이르면 포키에 세션당 한 번 GOAL_ADD_PROMPT를 생성한다.

## 확인한 경로

- 수정한 목표 프로필 저장, 형식 오류 거절, 내부 확장 결과 저장
- 여러 할 일의 순서, 세션 중 추가와 재시도, 오래된 요청의 충돌 응답, 3개 상한
- 목표 집합 밖 매칭 ID 보류, 이전 목표 버전의 비동기 판정 차단
- NOT_ENOUGH 누적 제외, FAR 599초에서 600초가 될 때 최초 제안 생성, 조회·포키 발송 확인·사용자 응답
- 발송 확인 없이 만료된 할 일 추가 제안 이후에도 이탈 알림 생성
- Java 25와 H2 회귀 테스트, 격리한 PostgreSQL 16의 V1~V32 마이그레이션 적용
- 목표 생성 응답 유실을 가정해 같은 멱등 키로 재시도하면 동일 목표가 반환되고, 본문을 바꿔 재사용하면 409를 반환하는 것을 확인했다.

## 연동 조건

기존 단일 목표 API 요청과 섞여 동작한다. goals 추가 필드를 엄격히 거절하는 구버전 AI에서는 분석이 미완료될 수 있으므로, Backend보다 새 AI를 먼저 배포한다. 운영 macOS와 실제 외부 프로필 모델 연결은 별도 환경에서 확인한다.
