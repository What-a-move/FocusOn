# 학습 목표 저장·상세 조회 구현 계획

> 상태: 수동 목표 저장·조회 구현 및 자동 테스트 완료. AI 확인 이력 연동과 최종 검증은 미완료다.

## 기본 정보

- 관련 Issue: [#87](https://github.com/What-a-move/FocusOn/issues/87)
- Branch: `feat/87-goal-create-read`
- 기준: Notion `FocusOn API 명세서`, ERD, 기존 인증·공통 응답 구조
- 대상: `POST /api/v1/goals`, `GET /api/v1/goals/{goalId}`

## 구현 범위

- 인증된 사용자의 목표와 소유 관계를 저장하고, 본인 목표만 조회한다.
- 목표 문구의 앞뒤 공백을 제거한 후 2~40자를 검증하고 오류는 `400 GOAL_TEXT_INVALID`로 처리한다.
- 수동 확정 목표를 저장하고 `201`로 목표 ID, 문구, 확정 출처를 반환한다. 조회는 `200`으로 같은 공개 정보를 반환한다.
- 존재하지 않거나 다른 사용자 소유인 목표, 삭제된 목표 및 유효하지 않은 ID는 `404 GOAL_NOT_FOUND`로 처리한다.
- 최신 dev의 V5·V6 이후 Flyway V7과 목표 Entity·Repository, 요청·응답 DTO, Swagger 설명을 추가한다.
- 명확성 확인 이력 검증은 선행 기능이 없어 구현하지 못했다. AI 확정은 임시 `503`이며 수동 확정에 포함된 명확화 ID는 사용자 승인에 따라 검증·저장하지 않는다.

## 제외 범위

- 목표 명확성 확인 API 자체, 목표 수정·삭제, 학습 세션.
