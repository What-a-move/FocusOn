# 화면 분석 실행 기록 보관 기간 정리

- 이슈 #311. [데이터 보관 정책](../../../docs/DATA_PRIVACY.md)의 세션 종료 후 90일을 적용한다.
- 종료·자동 종료된 세션의 서버 종료 시각으로 기한을 계산한다. 기본 5분마다 분석 행을 최대 500건 읽고, 분석 행 ID 커서로 이어서 처리한다.
- 후보를 세션별로 묶고 사용자 → 세션 순서로 잠근 뒤 종료 상태와 기한을 다시 확인한다. 해당 판정의 개입 참조를 해제하고 분석 행을 같은 트랜잭션에서 삭제한다. 실패한 세션의 작업은 롤백하고 다음 세션에서 계속한다.
- 개입 이벤트, 전송 이력, 세션 및 리포트는 보존한다. 소유자가 조회한 종료 세션이 90일 경계에 도달하면 정리 배치 완료 시점과 관계없이 기존 응답 형식의 빈 배열을 반환한다.
- 격리 PostgreSQL에서 90일 경계, 정상·자동 종료, 개입 외래 키와 전송 기록, 반복 실행을 검증한다.
