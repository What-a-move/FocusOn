## 1. 하루 목표 고정이 세션 명령 버전을 올림

- 발견: 전체 테스트(2026-11-27). 세션 시작 직후 버전이 0이 아니라 1이어서 일시정지·종료 등 `If-Match-Version` 명령이 409로 실패했다.
- 원인: 세션을 저장한 뒤 하루 목표를 넣어, 같은 트랜잭션에서 한 번 더 갱신(낙관적 버전 증가)이 일어났다.
- 조치: 세션을 처음 저장하기 전에 하루 목표를 넣는다.
- 검증: `SessionApiTests.sessionStartFreezesDailyTarget`(버전 0, 이후 설정 변경에도 고정값 유지), 기존 세션 명령 테스트 통과.
