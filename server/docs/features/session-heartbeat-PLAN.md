# 세션 Heartbeat·무신호 종료 계획

- Issue #167, `feat/167-session-heartbeat`. 사용자 제공 세션 설계·상태 전이 정책과 이슈를 기준으로 한다.
- Desktop의 인증 사용자·실행 기기, 관측 순서 및 누적 시간을 확인한다. 수신 시각과 클라이언트 관측 시각을 분리한다.
- 같은 시각 재전송과 누적 시간이 증가하지 않은 과거 관측은 무시하고 서버 수신 시각도 갱신하지 않는다. 시계 역행 시 누적 시간이 증가하면 시간 검증 후 복구한다.
- 정리 작업은 잠긴 사용자와 실패한 후보를 건너뛰고 다른 후보를 처리한다.
- 미래 관측과 비정상적인 누적 시간 증가는 기존 일시정지 기준과 같은 서버 경과 시간 + 30초 허용 범위로 제한한다. 이는 구현상 방어 기준이며 최종 API 정본과 별도 대조가 필요하다.
- 60초는 계산 가능한 후보이며 상태를 변경하지 않는다. 180초 이후 최신 생존 기준을 다시 확인해 ABANDONED로 전이하고 미확인 시간을 더하지 않는다.
- 일반 heartbeat는 명령 버전을 바꾸지 않는다. 목표 도달 및 자동 종료의 상태 전이는 버전을 증가시킨다.
- 사용자 행 잠금과 세션 행 잠금·조건부 갱신으로 명령·heartbeat·정리 작업의 경합을 처리한다.
- Notion 연결 페이지는 접근이 거부되어 사용자 제공 두 정책 본문과 이슈 및 로컬 계약을 대조했다. 자동 테스트, 실제 OAuth·Swagger, PostgreSQL 경합과 기존 DB 보존 검증 결과는 분리해 보고한다.
