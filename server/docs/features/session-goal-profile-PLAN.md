# 세션 할 일과 목표 프로필 연동 계획

- 기능 ID와 근거는 재설계 DR-024·DR-030, #298·#319다.
- 목표 상세·명확화 응답에 검증한 세분화를 노출하고 사용자 수정본을 저장한다. 초안이 없으면 내부 Goal AI를 호출하고 실패 시 프로필 없이 저장한다.
- Desktop은 세션 시작에 순서가 있는 목표 1~3개를 보내며 기존 단일 목표 요청도 지원한다. 실행 중 목표 추가는 실행 Desktop만 허용하고 목표 집합 버전은 세션 명령 버전과 분리한다.
- 분석은 세션에 저장한 목표와 프로필 사본을 전송한다. 반환된 매칭 ID의 소속을 확인하고 화면 원문 없이 매칭 정보만 저장한다.
- 완료 조건은 기존 단일 시작, 여러 목표 순서·소유권, 동시 추가·재시도, 오래된 판정, 프로필 검증, 분석 결과 저장 각 경로 확인이다.
