# 학습 메신저 보호 독립 리뷰

별도 컨텍스트에서 #383의 보호 입력, 관측 순서, 응답, DB 제약과 이탈 집계를 확인했다.

1. **Medium** — JSON 역직렬화가 알 수 없는 키를 버려 메신저 요청의 본문 혼입을 구분할 수 없었다. 요청·메타데이터에서 미정의 키가 있었다는 사실만 보존하고 메신저 관측에서 거절한다. 다른 요청은 기존처럼 미정의 필드를 무시한다.
2. **Low** — 집계 테스트가 구간의 열림과 닫힘만 확인했다. 고정 시각의 합성 테스트에서 미등록 시간이 이탈 비율의 분자와 분모에 포함되고 학습용 시간이 양쪽에서 빠지는지를 확인한다.
3. **Low** — V38 마이그레이션에 복구 순서를 추가했다.
