# 온보딩 준비 상태 독립 리뷰

2026-10-28: 독립 리뷰에서 Desktop별 상태를 사용자 공통 값에 저장해 다른 기기에 영향을 주는 문제와 프로필 동시 저장 문제를 발견했다. 로그인·auth/me·users/me·profile 응답은 공통 Desktop별 계산을 사용하도록 수정하고 프로필 갱신은 사용자 행을 잠근다. Extension 인증 조회는 연결 Desktop을 기준으로 계산한다. 독립 재검토에서 추가 확정 P1/P2는 없었다. 동의 철회 회귀를 추가했다. 동시 부분 갱신 및 family 자연 만료의 별도 경계 테스트는 남았다. 리뷰어는 테스트를 직접 실행하지 않았다.
